쪽집게 = **자격증 도메인별 Graph RAG + 훈련 콘텐츠 자동 생성 엔진의 MVP**

**구현 핵심 (진산님 언어):**

- 수험생 가치: "모르는 것을 정확히 알려주고, 외우게 해준다"
- 시험 본질: 단순암기(키워드/수식) + 과정암기(맥락/논리) + 반복훈련
- 출력: 4지선다/5지선다/단답/괄호/플래시/수식풀기/주관식 난이도별 — **무한 자동 생성**
- 목표 합격률: 60% (일반 2배)
- 브랜드: 간편·직관·수험생 맞춤

## 🎯 감사에서 내가 놓친 진짜 리스크 (진산님이 가르쳐주심)

**"정작 가장 큰 문제는 파악된 자격증 도메인별 지식을 바탕으로 훈련용 다양한 서비스를 무한히 생성이 가능하냐, 단 신뢰성·정확성이 담보되야 한다"**

6-페르소나 감사는 비즈니스·법무·운영 리스크에 치우쳤고, **"자동 생성 콘텐츠의 신뢰성·정확성 담보"** 이라는 엔진의 핵심 기술 리스크는 다루지 않았다. 이것이 실제 북극성.

**이 리스크가 Phase 2 이후 모든 설계 판단의 기준이 된다:**

- 문제 자동 생성기 → 정답 역방향 검증 + 교재 원문 대조 + 기출 정답 교차 검증
- 오답 후보 자동 생성 → "혼동 유형" 근거 노드 필수 (근거 없는 오답 금지)
- 괄호 채우기 / 단답 자동 생성 → Constants DB / Ontology ID 경유 (LLM 추론 금지)
- 수식풀이 → Formula Engine AST (CLAUDE.md Hard Limit 재확인)
- 암기법 → 역방향 복원 테스트 (Hard Limit 재확인)

**Hard Stop 기준 (재확인):** 정답 정확도 100% 미만이면 draft 유지, approved 금지.
