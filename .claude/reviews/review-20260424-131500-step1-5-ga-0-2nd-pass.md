## Pass 3 Security — 보안 감쇠 수식 평가

| 측면                          | 기존 (60/min + 2 RPC) | 수정 (20/min + RETURNING) | 감쇠          |
| ----------------------------- | --------------------- | ------------------------- | ------------- |
| race window                   | ~10-20ms (2 RPC 간격) | ~1ms 이하                 | **1-2 order** |
| enumeration /hour             | 3,600                 | 1,200                     | **3× 감소**   |
| 4,175 노드 전수 열거 (1 계정) | ~1.2 시간             | ~3.5 시간                 | 3× 지연       |
| 10 계정 병렬                  | ~7분                  | ~21분                     | 3× 지연       |

**정상 UX 영향**: 20/min = 3초/문제 간격. 모바일 flashcard 통상 4-8초/카드 → 차단 없음. 엣지 케이스 50개 몰아치기 2~3분 차단 (retryAfter 포함 응답으로 완화 가능).

## Devil's Advocate 잔여 공격 시나리오

- **A. 병렬 워커 enumeration (원 시나리오 A)**: 동일 user_id 10 탭 → D1 PK 직렬화로 실효 한도 20/min 유지. **거의 완전 해소**.
- **B. 계정 팜 enumeration (신규)**: 100개 계정 자동 생성 → 2,000/min → 4,175 노드 2분 내 열거. **CAPTCHA + signup rate-limit + email verification** 필수 (이월 법무 묶음 확인됨).
- **C. 429 타이밍 oracle (신규)**: 429 응답 body 길이 차이 + 타이밍으로 한도 도달 여부 공격자 감지. sleepJitter 429 에도 적용 필요 (NM-4).
- **D. D1 primary failover 1-2초 window**: 공격자 의도 제어 어려움. 낮은 위협.
