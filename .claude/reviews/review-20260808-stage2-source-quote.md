## 1. ★이번 리뷰의 핵심 — "세 방어선이 같은 맹점을 공유했다"

**렌즈 ① CRITICAL-1**: `LAW-183`(요령 제17조 재검토기한) 백필값 **2,325자 중 95%(2,207자)가 다른 문서**였다 —
부칙 + **[별표 1] 농작물 보험금 산정 표 전문** + 페이지 푸터. pdfplumber 컬럼 인터리빙으로 산식까지 뒤엉킨 상태.

- **기전**: `NEXT_ARTICLE_RE` 가 "다음 조문"만 절단점으로 삼았는데, **문서 마지막 조문**은 다음 조 마커가
  없어 `rest` 를 통째로 삼켰다.
- **왜 아무도 못 잡았나 — 이게 진짜 발견이다**:
  | 방어선 | 무엇을 봤나 | 왜 통과시켰나 |
  | :-- | :-- | :-- |
  | `gate_check.py` 5종 | 제목·조번호·description 비동일·길이·전수 | 전부 **머리**만 봄. `MAX_LEN=6000` > 2,325 |
  | `review-sheet.md` | 머리 90자 | 완벽히 정상으로 보임 |
  | e2e 테스트 | `!= ''`, `!= description` | 둘 다 참 |
  **세 방어선이 전부 머리 편향을 공유**했다. 그리고 0047 은 `source_quote` 를 NULL→값 1회로 고정하므로
  **적용 후에는 영구히 못 고친다**(렌즈① CRITICAL-2 실측: 값→값·값→NULL·DELETE 전부 ABORT).
- **만약 그대로 적용됐다면**: 2,207자짜리 무관 바이그램 풀 덕에 STAGE 3 가 **무엇을 주장해도 통과**한다 —
  0047 헤더가 스스로 금지한 _"전문 투입 → 접합 인용 coverage 1.0"_ 이 **첫 백필에서 실현**됐을 것이다.

**처분**: 절단점에 **문서 경계**(`^부칙`·`^[별표`·`^N. `·페이지 푸터) 추가 → LAW-183 **2,325→117자**,
LAW-201 316→116자. 최대 길이 2,325→**707**. 그리고 **꼬리 게이트 2종 신설**(7f 오염 탐지 · 7g description 대비 배수).
