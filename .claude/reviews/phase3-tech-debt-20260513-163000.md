- **quality:** "apps/web 0 테스트는 Playwright E2E로 한꺼번에 잡는다" 가정은 **거짓 안전**. unit (분기 망라) + integration (state machine) + E2E (smoke) 3층 구조 정답.
- **backend:** "Year 2 멀티시험 활성화 안 될 수도 있음" → C-D1 댕글링 FK는 손해평가사 단일 시험 내 교재 개정 시 매년 발생.
