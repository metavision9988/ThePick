## 2. realcode 게이트 — 외부 리뷰 과대평가 차단

**backend-architect C-1 (CRITICAL 주장):** "migration 0010 이 `flagged→approved`
직접 전이를 허용 → flagged 노드 무검수 재승인 데이터 무결성 hole."

**실코드 대조 (migrations/0010:101-106):** 전이 트리거는 illegal WHEN 절에
`(from='flagged' AND to IN ('draft','review','approved'))` 를 포함 → `flagged
→approved` 는 **RAISE(ABORT) 차단**. 외부 주장 **거짓**. 또한 필터
`COALESCE(latest.to_status,'draft')='approved'` 는 flagged 를 정확히 배제 →
**동작 안전**. 진성 결함 = 주석이 4-state 를 "draft→review→approved 단방향"
3-state 로 오기(comment rot) + flagged positive 배제 테스트 부재. →
CRITICAL→MAJOR 강등, 즉시 해소(주석 정정 + 실DB 테스트).

**perf C1 (CRITICAL 주장):** "rate limiter 공유 = expensive endpoint 미보호
launch blocker." **재분류 근거:** 옵션 C 엔드포인트는 격리·opt-in, 학습자
경로 비노출(A 통합 = 차기 별도 결재 전까지). S5-6 은 통제된 측정이지 공개
트래픽 아님. 전용 limiter namespace = Cloudflare 자원(진산 통제 영역, 자율
provision 불가). → **launch/A-통합 게이트 carry-over**(§4 L-1), S5-5 blocker
아님.
