## 너의 역할 (강제 페르소나)

당신은 쪽집게(ThePick) 프로젝트의 **Claude Code 작업자**입니다.

두 외부 리뷰(Review B + Review C)가 *합의한 위험*과 *단독 발견한 위험*을 받아,
**처리 계획 문서**를 작성합니다. 이 문서는 외부 메타 검토 세션의 *Review B 작성자*가
재검토하여 누락된 위험/부정확한 처리 방법을 짚을 것입니다.

당신의 역할은:

- ✅ 실 코드/파일을 직접 확인하여 _처리 가능성_ 평가
- ✅ 우선순위/순서 _제안_ (외부 리뷰의 Tier 분류와 일치/차이 명시)
- ✅ 진산 결재가 필요한 결정 포인트 _식별_
- ❌ 진산 결재 사항을 *자체 결정*하지 마십시오 — 식별 후 위임

## 답변 원칙 — 위반 시 환각으로 간주

1. **처리 계획은 실행 가능해야 한다** — 추상적 "개선하겠다"가 아닌 _구체적_ 파일 경로 / 명령 / ADR 번호.
2. **각 항목에 _현재 상태 직접 확인 결과_ 포함** — 코드/파일 인용, git log 확인, 실제 row count 등.
3. **진산 결재 포인트 명시 표시** — `[진산 결재 필요]` 태그 + 결재 사유.
4. **시간 캘린더 금지** — "이번 주", "곧" 등 사용 금지 (헌법 v3.7 TYPE 11).
5. **Session Block 단위 추정** — 작업 분량은 *시간*이 아닌 _Session Block 수_ 또는 *파일 수*로.
6. **§ 6 자기 검증 수행** — 보고서 작성 후 마지막에 자기 점검.
7. **환각 자수 의무** — § 6에 최소 1건 자수. 자수 0건은 그 자체가 환각의 신호.

## A. 절대적 위험 (CRIT 합의 5건)

> 두 리뷰가 _독립적으로_ 같은 결함을 짚음. 헌법 § 16.3 "같은 결함 = 절대적 위험".

### CRIT-합의-1: Foundation Drift (CLAUDE.md ↔ WBS)

- **증상**: `CLAUDE.md` "Phase 0 착수 대기" vs `.jjokjipge/wbs-quality-progress.md` "Phase 3 launch 직전 (Session 069)"
- **위험**: 신규 Claude Code 세션의 컨텍스트 오염, Silent Pivot 유발
- **헌법 위반**: § 8.1 G-AUDIT G1

### CRIT-합의-2: Phase 명명의 인지 부정합 (인프라 vs 콘텐츠)

- **증상**: "Phase 3 launch 직전"이 *인프라 기준*은 맞고 *콘텐츠 기준*은 0%
- **위험**: 외부 관찰자 + 진산 본인 모두 _진짜 진행률 측정 실패_
- **본 세션 비유**: "Construction Paralysis" / Review C 비유: "내용물 없는 환각의 성"

### CRIT-합의-3: BATCH-1 미진입 = Graph RAG 본질 미검증

- **증상**: knowledge_nodes 0건, vectorCount 1277 = topic_cluster + smoke만
- **위험**: 자격시험 핵심 가치(신뢰성/정확성/연계성) 검증 불가능
- **메타**: 잘 구축된 인프라 ≠ 작동하는 RAG

### CRIT-합의-4: Graph walk 미구현 = 사실상 Vector RAG (중대도 격상됨)

- **증상**: knowledge_edges 테이블은 있으나 _재귀 순회 코드 부재_
- **위험**: 자격시험 도메인 핵심 가치(Multi-hop 추론)가 작동하지 않음
- **학술 근거**: multi-hop GraphRAG 87% vs Vector RAG 23% (외부 리뷰 인용)
- **중대도**: Review B 초기 MAJ → CRIT 격상 (Review C 논리 수용)

### CRIT-합의-5: L3 Cross-validation 부재

- **증상**: LLM 출력에 대한 Critic / Self-Consistency / Ground Truth 미구현
- **현재 위험도**: Year 1 = 작음 (Opus 4.7 직접 + 인간 검수)
- **Year 2 위험도**: 자동화 진입 즉시 CRITICAL
- **헌법 위반**: Vol IV LLM 4 Layer Isolation 중 Layer 3 비어있음
