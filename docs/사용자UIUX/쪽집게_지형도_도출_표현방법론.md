# 쪽집게 1차 — 지형도(Field Mapping) 도출 & "숲을 보게 하는" 표현 방법론

> 암기 **이전**의 선행 단계. 두 가지를 담았다.
> **Part 1 — 내부 인프라에서 지형도를 도출한다** (손으로 그리지 않는다)
> **Part 2 — 그 지형도로 학습자가 "숲을 보게" 만드는 표현·방법론** (모바일/데스크탑)

---

## 0. 관점 전환 3가지 (이 문서의 축)

1. **지형도 ≠ 목차.** 목차는 단편적 결과물을 나열한 평면 카탈로그다. 진짜 지형도는 당신 데이터에서 도출한 **가중치·긴장(tension) 반영 그래프** — 어디가 하중벽이고 어디가 어려운 곳인지가 보이는 지도다.
2. **당신 그래프의 진짜 직업은 검색이 아니라 숲 지도였다.** graph-walk의 RAG 정답률 기여 0(측정 완료)은 그래프를 폐기하라는 뜻이 아니라, **사람의 지형도**로 재배치하라는 신호다. Field Mapping이 정확히 그 용도다.
3. **Vector(목적)는 산식에 있다.** 보험금 산식(F-14: `max(가입금액 × (피해율 − 자기부담비율), 0)`)이 도메인의 중력우물이다. 변수(피해율·자기부담비율·평년수확량…)를 역추적하면 "왜 이 개념을 알아야 하는가"가 자동으로 나온다.

# Part 1. 지형도 도출 — 내부 인프라에서 (선행)

## 1-0. 패러다임: 당신은 이미 지형도 재료를 다 갖고 있다

핵심 발견: **18종 엣지 타입이 곧 노박 개념도의 "관계 라벨(linking phrase)"이다.** 즉 당신의 `knowledge_edges`는 이미 기계가 만든 **전문가 골격(expert skeleton) 개념도**다. 지형도는 새로 그리는 게 아니라 이 데이터를 **6개 층으로 사영(projection)** 하면 나온다.

## 1-1. 지형도의 6개 층 → 도출 소스 매핑

| 층                          | 무엇을 보여주나                          | 도출 소스 (내부 인프라)                                                                                |
| --------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| ① **뼈대 (Skeleton)**       | 대–중–소 분류 위계 = "빈 방"의 벽        | `topic_clusters.lv1/lv2/lv3` + 엣지 `GOVERNED_BY` · `DEFINED_AS` · `CONTAINS_TABLE/HAS_ROW/HAS_COLUMN` |
| ② **성장 순서 (Growth)**    | 무엇을 먼저 심어야 하나 = 학습 경로      | `PREREQUISITE` · `DEPENDS_ON` · `REQUIRES_INVESTIGATION`                                               |
| ③ **하중벽 (Load-bearing)** | 숲이 **무엇을 위해** 존재하나 = 우선순위 | `topic_clusters.exam_frequency` + `USES_FORMULA` 밀집도                                                |
| ④ **긴장 (Tension)**        | **어려운 곳** = 전문가가 주목하는 곳     | `EXCEPTION` · `DIFFERS_FROM` · `CROSS_REF` · `SHARED_WITH`                                             |
| ⑤ **연산 척추 (Spine)**     | 도메인 중력우물                          | `formulas`(F-14 등) · `USES_FORMULA` · `TIME_CONSTRAINT` · `APPLIES_TO`                                |
| ⑥ **목적 (Vector)**         | 왜 존재하나                              | 시험 미션 + 산식 변수 역추적 + `GOVERNED_BY` 루트                                                      |

각 층은 **가중치**를 갖는다: 노드 크기 = `exam_frequency`, 엣지 굵기 = 관계 강도, 색 = 층 종류. 목차와 달리 **무엇이 중요하고 무엇이 어려운지가 지도 위에서 즉시 보인다.**

## 1-2. 긴장(Tension)이 지형도의 핵심이다

첫 심층조사에서 확인했듯, 진짜 지형도 파악은 "도메인을 지배하는 힘의 역학(Tension)을 역설계"하는 것이다. 당신 그래프는 이 긴장을 이미 타입으로 분리해 뒀다.

- `EXCEPTION` → 원칙-예외 쌍 = 함정이 숨는 곳
- `DIFFERS_FROM` → 헷갈리는 유사쌍(작물 교차 등) = 실점 다발 지역
- `CROSS_REF` → 조문 준용 = 경계가 흐린 곳
- `SHARED_WITH` → 1차↔2차 공유 = 재사용되는 개념

지형도에서 이 엣지들을 **별도 레이어("함정 지도")로 켜면**, 학습자는 "이 숲에서 조심할 벼랑"을 먼저 본다. 이것이 목차가 절대 못 하는 일이다.

## 1-3. Vector Alignment 도출 — "왜?"를 자동 생성

"내가 왜 이 개념을 알아야 하는가"의 방향성을 손으로 쓰지 않고 데이터에서 뽑는다.

- **미션 루트:** 손해평가의 임무(피해사실 확인 → 보험가액·손해액 평가)가 모든 가지의 최상위 "왜".
- **산식 역추적:** F-14 `보험금 = max(가입금액 × (피해율 − 자기부담비율), 0)` → 변수마다 "이 값을 구하려면 어떤 개념·법령·수치가 필요한가"를 `USES_FORMULA`/`DEPENDS_ON`으로 역추적 → **각 개념이 존재하는 이유**가 산식으로 환원된다.
- **문제-우선 프레이밍:** 각 클러스터를 "이 부분은 어떤 분쟁·오산정을 막으려 존재하는가"로 라벨링(EXCEPTION 클러스터 = 분쟁 다발 지점).

## 1-4. 산출물: "빈 방" = 전문가 골격 지도

위 6층을 합치면 **선행 조직자(advance organizer)** 가 된다 — 내용보다 한 단계 높은 추상에서, 학습 **전에** 제시하는 개념적 다리. 노박식으로 말하면 **빈 슬롯을 가진 전문가 골격 개념도**이고, 학습자의 숙련도가 그 방을 채워 나간다. 이 골격이 있어야 이후 암기한 용어가 흩어지지 않고 제자리에 꽂힌다.

# Part 2. "숲을 보게 하는" 표현·방법론

> 근거 3축: **선행 조직자**(Ausubel — 높은 추상 구조를 먼저, 점진 분화 + 통합 조정) · **개념도**(Novak — 위계 + 라벨 달린 관계선 = 당신의 18 엣지) · **정보 시각화 만트라**(Shneiderman — 개관 먼저 → 확대·필터 → 요청 시 상세; 시맨틱 줌·초점+맥락).

각 항목: **동작 · 근거 · 어떤 도출층을 보여주나 · 모바일 · 데스크탑 · 주의**

### F1. 조감 오버뷰 (Overview-first 랜딩)

- **동작:** 진입 시 **가장 높은 추상**만 — 3과목 → 대분류 몇 개. 상세는 아직 감춤.
- **근거:** "개관 먼저." 슈나이더만이 든 대표 예가 "먼저 목차·코스 개요로 조망시켜라".
- **보여주는 층:** ① 뼈대 최상위 + ③ 하중벽(빈도 큰 가지 크게).
- **모바일:** 3과목 카드 + 각 과목 하중벽 1~2개. **데스크탑:** 전체 대분류 한 화면.
- **주의:** 여기서 절대 노드 다 뿌리지 말 것(헤어볼).

### F2. 시맨틱 줌 지형도 (Semantic Zoom)

- **동작:** 확대할수록 **노드가 늘고 표현이 바뀜**(과목→장→절→개념). 축소하면 다시 뭉침.
- **근거:** 시맨틱 줌 — 상세 수준 이동 시 정보량과 표현을 함께 변경해 헤어볼 방지.
- **보여주는 층:** ①②④를 줌 레벨별로.
- **모바일:** 핀치 줌 + 레벨 인디케이터. **데스크탑:** 스크롤/줌 슬라이더.
- **주의:** 각 레벨 노드 수 상한(예: 화면당 ≤ 12).

### F3. 초점+맥락 (Focus + Context / 바이포컬)

- **동작:** 현재 개념을 확대하되 **주변 숲을 계속 보이게**(어안/바이포컬). "여기가 어디인지" 안 잃음.
- **근거:** focus+context는 관심 영역 상세 + 주변 맥락 유지로 방향 감각 보존.
- **보여주는 층:** ① + 현재 노드의 ④ 긴장 이웃.
- **모바일:** 상단 미니맵 + 하단 상세. **데스크탑:** 바이포컬 한 화면.
- **주의:** 왜곡이 거리 오해를 부를 수 있으니 위계엔 신중.

### F4. 하중벽 히트맵 오버레이 (exam_frequency 가중)

- **동작:** 노드 크기·농도 = **출제빈도**. "이 숲이 무엇을 위해 존재하는지"가 한눈에. 위에 **내 숙련도** 색을 겹침.
- **근거:** 하중벽 = 숲의 목적. 우선순위·과락 방어 직결.
- **보여주는 층:** ③ 하중벽 + 학습자 상태.
- **모바일:** 크기+색 이중 인코딩. **데스크탑:** 필터 슬라이더(빈도 X 이상만).
- **주의:** 빈도 낮아도 선수개념이면 작게라도 유지(성장 순서).

### F5. 긴장선 강조 — "함정 지도" 레이어

- **동작:** `EXCEPTION`/`DIFFERS_FROM`/`CROSS_REF`를 **별도 색·점선**으로. 토글로 "함정만 보기".
- **근거:** 도메인의 진짜 난도는 긴장선에 있다 = 전문가 초점.
- **보여주는 층:** ④ 긴장.
- **모바일:** 함정 토글 버튼. **데스크탑:** 레이어 체크박스.
- **주의:** 기본은 꺼두고, 어느 정도 골격 잡힌 뒤 켜기(초보 과부하 방지).

### F6. 선행 경로 하이라이트 (Prerequisite Trail)

- **동작:** 한 개념을 고르면 `PREREQUISITE` 사슬을 **성장 순서 트레일**로 밝힘 — "이걸 알려면 먼저 여기".
- **근거:** 위계적 개념도는 최적 학습 순서를 시사.
- **보여주는 층:** ② 성장 순서.
- **모바일:** 탭→상류 경로 애니메이션. **데스크탑:** 호버→경로 하이라이트.
- **주의:** 사슬 3~7단계로 청킹.

### F7. 목적 서사 / 문제-우선 프레이밍 (Vector 선행 조직자)

- **동작:** 각 가지 진입 시 "이 부분은 어떤 문제(오산정·분쟁)를 푸는가"를 **한 문단 서사**로 먼저. 산식 중력우물을 루트 이야기로.
- **근거:** 서사형 선행 조직자(효과크기 ≈ 0.53)는 사전지식을 자극하고 새 정보의 틀을 제공.
- **보여주는 층:** ⑥ 목적 + ⑤ 척추.
- **모바일/데스크탑:** 가지 진입 카드 1스크린.
- **주의:** 요약이 아니라 **더 높은 추상의 다리**여야 함(목표 나열 금지).

### F8. 빈 방 스캐폴드 (Expert-Skeleton, 내용 前 제시)

- **동작:** 도출된 골격을 **빈 슬롯 상태로 먼저** 보여주고, 학습이 진행되며 방이 채워짐.
- **근거:** 선행 조직자 + 전문가 골격 개념도. 틀이 먼저 있어야 용어가 꽂힌다.
- **보여주는 층:** ① 뼈대(빈 슬롯).
- **모바일:** 채워진 방 vs 빈 방 색 구분. **데스크탑:** 골격 전체 + 채움 진행률.
- **주의:** 빈 방이 너무 많으면 위압 → F1처럼 상위부터.

### F9. MOC 한 장 지도 (Map of Content = 코스 개요)

- **동작:** 과목당 1스크롤 개요 아웃라인 — 그래프가 헤어볼일 때의 **우아한 저하** 대안.
- **근거:** 슈나이더만의 "코스 개요로 먼저 조망". 위계 아웃라인이 방향 잡기 최적.
- **보여주는 층:** ① + ③(각 줄에 빈도·숙련 배지).
- **모바일:** 접이식 아웃라인(주력). **데스크탑:** 좌측 MOC + 우측 상세(overview+detail).
- **주의:** 노드 폭증 시 그래프 대신 이걸 기본값으로.

### F10. 진행형 분화 뷰 (Progressive Differentiation)

- **동작:** 가장 일반 개념 → 단계적으로 하위 분화. 아코디언/드릴다운.
- **근거:** 아우스벨의 점진적 분화 — 포괄 개념부터 구체로.
- **보여주는 층:** ①을 단계 공개.
- **모바일:** 탭 확장. **데스크탑:** 트리 드릴.
- **주의:** 한 번에 한 단계만 열기.

### F11. 통합 조정 뷰 (Integrative Reconciliation — "숲은 이어져 있다")

- **동작:** 하위 영역 간 교차연결(`SHARED_WITH`·`CROSS_REF`)을 부각 — 특히 **1차↔2차 공유 노드**로 "세 섬이 아니라 한 숲".
- **근거:** 통합 조정 = 하위 도메인 상호연결 이해.
- **보여주는 층:** ④ 긴장(공유·준용).
- **모바일:** "이 개념이 또 쓰이는 곳" 칩. **데스크탑:** 교차 엣지 하이라이트.
- **주의:** 과다 연결은 헤어볼 → 강한 것만.

### F12. 연산 척추 뷰 (Formula-Centered Map)

- **동작:** 보험금 산식을 **중앙**에 두고, 변수(피해율·자기부담비율…)를 밖으로 방사 → 각 변수를 정의하는 개념·법령·수치로 연결.
- **근거:** 중력우물 시각화 = Vector의 물리적 구현. "왜 이 개념이 중요한가"가 선으로 보임.
- **보여주는 층:** ⑤ 척추 + ⑥ 목적.
- **모바일:** 산식→변수 단계 카드. **데스크탑:** 방사형 전체.
- **주의:** 2차 색이 강하지만 1차 개념의 목적 정렬에도 유효.

### F13. "당신은 여기" 오리엔테이션 (Persistent You-Are-Here)

- **동작:** 모든 상세 화면에 **미니맵**으로 숲 속 현재 위치 표시.
- **근거:** overview+detail 연동 — 상세에 빠져도 맥락 유지.
- **보여주는 층:** ① + 현재 핀.
- **모바일:** 상단 접이식 미니맵. **데스크탑:** 고정 사이드 미니맵.
- **주의:** 항상 켜두되 작게(주의 분산 방지).

### F14. 서사 투어 / 가이드 워크 (First-run Guided Tour)

- **동작:** 최초 진입 시 숲을 **자동 비행**하며 하중벽 노드를 짚는 내레이션 투어.
- **근거:** 온보딩용 선행 조직자 — 전체 조망을 능동 이전에 한 번 심어줌.
- **보여주는 층:** ①③⑥ 순회.
- **모바일:** 스텝 카드 스와이프. **데스크탑:** 자동 팬/줌 + 자막.
- **주의:** 스킵 가능, 재관람 가능. 1회 3분 이내.

## 2-B. 모바일 vs 데스크탑 (+ 헤어볼 Hard Limit)

|           | 모바일(80%)                           | 데스크탑(20%)                   |

| 지도 조작 | 핀치 줌 · 탭 드릴                     | 스크롤 줌 · 호버 하이라이트     |

> **헤어볼 Hard Limit:** 노드 1,000+개 원시 force 그래프는 의미 없는 거미줄이다. 방어: **시맨틱 줌(F2) + 화면당 노드 상한 + MOC(F9) 폴백 + 필터.** 소형 화면은 그래프 탐색 효율이 가장 낮으므로 **모바일 기본값은 그래프가 아니라 MOC 아웃라인**으로 두고, 그래프는 "펼쳐보기"로.

## 2-C. 구현 우선순위 (기존 자산 기준)

이미 있는 **D3 Force Graph + `topic_clusters`(lv/빈도) + 18 엣지 타입 + `formulas`** 재사용해 아래 순으로.

1. **F1 조감 + F9 MOC** — 도출 6층 중 ①③만으로 즉시 "숲 먼저"(가장 싸고 효과 큼).
2. **F4 하중벽 히트맵 + F13 유아히어** — 우선순위·오리엔테이션.
3. **F2 시맨틱 줌** — 헤어볼 방어(그래프를 사람용으로 정식 전환).
4. **F5 긴장선 + F6 선행 경로** — 난이도·순서(④②).
5. **F7 목적 서사 + F12 연산 척추** — Vector 정렬(⑤⑥).
6. **F8 빈 방 스캐폴드 + F14 투어** — 온보딩 선행 조직자.
7. 나머지(F3·F10·F11)는 필요 시.

측정(G-1 정신): F1/F4 조망군 vs 미조망군의 **사례·전이 문항 정답률** 차이로 "그래프의 새 존재이유"를 실측한다(과거 graph-walk=0처럼, 순기여 0이면 표현도 은퇴).

### 한 줄 요약

지형도는 **그리는 게 아니라 당신의 18 엣지·빈도·산식에서 6층으로 도출**되고(뼈대·성장순서·하중벽·긴장·척추·목적), "숲을 보게 하는" 법은 **개관 먼저 → 시맨틱 줌 → 요청 시 상세** 위에 **하중벽 히트맵·긴장 레이어·목적 서사**를 얹는 것이다. 검색에서 은퇴한 그래프의 진짜 직업이 바로 이 숲 지도다.
