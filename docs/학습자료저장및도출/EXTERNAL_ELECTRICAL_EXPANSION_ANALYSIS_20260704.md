### 기술 스택 (Architect) — ★S10의 심장

- **풀이 엔진 = lcapy** (Python+SymPy): 넷리스트 입력 → 기호해+수치해+**단계별 유도** 자동 산출. 교육자료 생성 사례 검증됨.
- **렌더 = schemdraw** (matplotlib→SVG, 순수 Python 경량) 또는 lcapy 내장 렌더.
- **⚠️ 결정적 제약**: lcapy 고품질 도면 = LaTeX+Circuitikz+PDF변환 무거운 툴체인 → **브라우저 런타임 불가, 둘 다 빌드타임 전용**. 파이프라인: [빌드타임 Python 사이드카: generator→lcapy solve→SVG→JSON(넷리스트+풀이단계+정답+SVG)] → 정적 배포(Cloudflare Edge) → [런타임 브라우저: 정적 JSON 로드+SVG 주입+KaTeX — 연산 없음].
- 클래스 B: 한국 수변전 표준 심볼(CT·PT·COS·PF·LA·ASS·MOF) 기본 지원 약함 — 커스텀 심볼셋+배치 규칙 엔진 신규. 풀이=규칙 검증(코드화 가능).
- 클래스 C: lcapy·SPICE 부적용 — 소형 부울/상태 시뮬레이터+래더 렌더러. 표준 패턴 유한 → 패턴 라이브러리.

### 파괴 검토 (Breaker) — 가드레일 원천

1. **무작위 토폴로지 생성 금지** — lcapy 공식 경고("고차 시스템 특이행렬") → **알려진 양호 토폴로지 템플릿에서 값만 난수화**. 자유 그래프 생성 금지.
2. **자동 배치(auto-layout)가 진짜 난제** — schemdraw·lcapy 모두 semi-automatic(방향 힌트 필수) → 템플릿마다 배치 힌트 사전 저작(인간 작업).
3. **"사일런트 드롭" 금지** — 깨진 문제를 런타임 방어로 숨기지 말고 **생성 시점 solver 검증으로 원천 차단**.
4. **기출 도면 수집 갭** — 기출 이미지→구조 추출은 Vision 필요. 초기엔 인간이 넷리스트 수기 입력.
5. **Solver-Validated Generation Gate**: G1 유일·유한해(특이행렬/발산 거부) / G2 난이도 경계 / G3 레이아웃 청결도 / G4 단위·유효숫자 — 하나라도 실패 = 폐기·재생성, 사용자 노출 절대 금지.

### Hard Rule 검토 (Sentinel)

- 회로 생성기는 LLM이 아니라 **결정론 알고리즘+solver** = "LLM 지식생성 금지" 위반 아님(오히려 정신 정합).
- 신규 리스크: "결정론적으로 생성됐지만 교육적으로 무의미한 문제" → 인간 검토 게이트 유지하되 **대상을 개별 문제→[생성 템플릿·배치 힌트·규칙셋] 승인으로 이동** 제안 — ★Hard Rule 7 강도 조절 사안 = ADR·진산 결재 필요(미결).
- admin localStorage 토큰 선수정(도면 저작 도구 추가 전).

### 학습자 관점 (Advocate)

수험생 니즈 = 다양성이 아니라 **표준 패턴의 숙달** → 임의 생성보다 표준 템플릿+미완성 채우기(빈칸)+즉시 채점이 가치.

### 최종 판정 (Mephisto)

1차 객관식 = ThePick 75~85% 재사용(회로도 대부분 렌더링으로 충분) / 클래스 A 생성+풀이 = lcapy 빌드타임으로 실현 가능(양호 템플릿 한정) / 2차 단답·계산 = 80% 재사용 / 2차 그리기(B·C) = 신규 엔진(임의 생성 아닌 템플릿 변형이 정답). 로드맵 E0(수직 관통 PoC: RLC 1문제 생성·풀이·SVG·PWA 렌더 + Gate G1 특이행렬 거부 테스트) → E1~E4.
