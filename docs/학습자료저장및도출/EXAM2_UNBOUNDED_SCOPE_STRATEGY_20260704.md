## §0 핵심 답 — 전기기사는 "무경계"가 아니었다

웹 실사 결과, **전기기사는 "정본 교재만 없는 유계(有界) 시험"으로 재정의**된다. 경계를 이루는 공식 자산 3종이 실재한다:

| 경계 자산                       | 실측                                                                                                                                                         | 역할                                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| ① **출제기준(큐넷 공시)**       | 현행 2024.1.1~2026.12.31, hwp 원문 다운로드+파싱 실증 완료 — **주요항목 ~30 / 세부항목 197 / 세세항목 ~679의 3단 topic hierarchy**                           | 커버리지의 **분모** (단 세세항목 다수 "~등" 열거 = 완전 폐포 아님 — "100% 적중" 단언 금지) |
| ② **KEC·전기설비기술기준 원문** | law.go.kr 행정규칙 무료 전문 + kec.kea.kr. 제5과목(설비기준)은 **원문 자체가 출제 모집단**                                                                   | 규정형 과목의 정본 — 1호 법령 축(LAW+SUPERSEDES) 동형                                      |
| ③ **지필 기출 아카이브**        | ~2022년 2회(2022.4.24)까지 문제+확정답안 공개분 대량(comcbt 등). **문제은행 방식은 공단 공식 명시** — 기출이 "과거 표본"이 아니라 **현행 모집단의 부분집합** | 실효 범위 히트맵 + Ground Truth                                                            |

⇒ 해법의 본질 = **"경계를 데이터로 제조"**: 출제기준(분모) × 기출 히트맵(실효 범위) × 규정 원문(정본). LLM은 배치·초안 단계에만 국한. 진짜 무경계 잔여분은 손해평가사 농학개론과 세세항목 "~등" 부분뿐이다(§5).

**단, 실사가 드러낸 구조적 절벽 2개**:

- **CBT 절벽 (GT 영구 동결)**: 2022년 3회부터 CBT 전환(공단 공식: 문제은행·문제 비공개·사후열람 불가) → **확정답안 있는 공개 기출은 2022년 2회에서 영구 동결**. 이후는 수험생 기억 기반 "복원분"만 유통(정답·보기 모두 공식 검증 불가) → GT 2계층 설계 필수(§4).
- **KEC 2021 대변동**: 2021.1.1 KEC 시행으로 설비기준 과목 출제 체계 교체 → **2020년 이전 기출의 설비 문항 다수가 현행 규정과 불일치** — "출제 당시 규정 vs 현행" 라벨 없이 적재하면 오답을 정답으로 가르치는 사고. `effective_date`를 스키마 1급으로(1호 E0-8 "시행시점 축 부재" 결함의 선제 차단). KEC는 연 1~3회 개정 + 소관부처까지 변동(산업부→기후에너지환경부 — 재검증에서 실사 시점 "최신"이 이미 구버전으로 판명된 실증) → **개정 모니터링 배치는 부속이 아니라 성립 조건**.

## §1 시험 실사 요약 (재검증 통과분)

- 필기 5과목: 전기자기학·전력공학·전기기기·회로이론및제어공학·전기설비기술기준. **4지 택일**, 과목당 20문항(총 100)/150분, 합격 = 과목당 40(과락)+평균 60. 연 3회, CBT 기간제(회차당 수 주 응시창 + 수험생별 무작위 출제) — **"특정 회차 대비"가 아닌 "문제은행 커버리지" 학습 모델 = FSRS와 구조 정합**.
- 문제은행 반복률 통설 50~80%("70% 기출 변형") — **공식 통계 부재, 수험가 통설** → 확보 아카이브로 자체 중복도 실측(spike S2) 후에만 설계 전제 승격.
- 필기 합격률 ~25.4%(단일 출처 추정). 응시자 규모(시장성) **미확보** — 비평 지적: comcbt·도타비 등 **무료 CBT 서비스가 포화한 성숙 경쟁 시장**이므로 차별화 논거(결정론 변형 생성·커버리지 정직성·FSRS) 검증 필요.
- 공학용 계산기 허용 → 문항 본질 = "식 세우기" = 산식 노드+변수 바인딩 모델과 동형.
- **전기 패밀리 중첩(진산 발화 확증)**: 전력공학·전기기기·설비기준 3과목은 기사/산업기사/공사기사/공사산업기사 **4종목 완전 공유**, 회로이론 계열도 공유(기사만 제어공학 +10문항), 고유 과목은 각 1개뿐 — **과목 7개로 패밀리 4종목 필기 커버**. 난이도 차등의 실체 = 과목 추가+계산 복잡도(토픽 자체는 공유).
- 2026.12.31 현행 출제기준 만료 → **2027 개정이 개발 기간 한중간에 공시될 예정 축**(대기 vs 착수+SUPERSEDES 흡수 = 결재 Q5).

## §3 권고 조합안 — "3원 경계 제조 + 과목 유형별 3트랙"

```
[골격]    (b) 출제기준 3단 온톨로지 = 커버리지 분모 (topic 계층 populate = 온보딩 1급 산출물)
[우선순위] (a) 기출 히트맵 = 실효 범위 (GT 2계층: 지필 공식분 Tier-1 / CBT 복원분 Tier-2)
[콘텐츠]  과목 유형별 3트랙:
  ─ 규정형(전기설비기술기준): KEC·기술기준 원문 조문 노드화 — 1호 gap-P1/P2 플레이북 거의 그대로.
    KEC 코드번호(211.2 등)가 book_page 축 문제를 원천 해소하는 안정 앵커. 이미지 0% = 즉시 착수 후보.
  ─ 계산형(회로이론·자기학·전력공학 일부): (c) 결정론 변형 생성 — formula-engine 재사용.
    이원 정본(ID=D1/계산=코드)+크로스워크 Day-1 강제 (1호 55건 드리프트 재발 방지).
  ─ 개념형(전기기기 서술·전력 암기): 기출 해설 노드화 + 세세항목 단위 개념 노드 (배치 draft→행당 검수).
[정직성]  (d) honest-refusal + 커버리지 대시보드 + "과락 방지 모드" 상품
[운영]    개정 모니터링 배치 + SUPERSEDES + effective_date 스키마 1급 (성립 조건)
```

**그림·회로도 문항 3안** (표본: 100문항 중 이미지 ~34 — 설비 0/전력 ~4/자기학 ~7/기기 ~9/**회로·제어 ~14** — 단일 표본, spike S4 재검증):

- (i) 스코프 제외(텍스트만 1단계): 비용 ~0, ~66/100 커버 — 단 **회로이론(과락 다발 과목)의 심장이 빠짐**
- (ii) Vision OCR 스텁 해소: 회로도 인식 천장 미조사 — 단독 채택 금지, spike 선행
- (iii) **구조화 표현(netlist/표/서술)**: 회로도를 텍스트 명세로 변환 적재 — 결정론적·검증 가능·formula-engine 직결. 품질 천장 최고, 초기 검수 비용 최고
- **권고 배치**: (i) 착수 → (iii) 회로이론 파일럿 20문항 스파이크 → (ii)는 (iii)의 **입력 자동화 도구로 재위치**(Vision이 netlist 초안 생성→인간 검수→결정론 자산. Vision 출력을 직접 콘텐츠로 쓰지 않아 환각 차단선 유지)
- ⚠️ **비평 C-6 (모순 정직 노출)**: 온보딩 시퀀스(그림 적은 과목 먼저)와 "과락 방지 모드" 상품 정의가 역방향 — 회로이론이 가장 늦게 커버되는데 과락 위험은 거기가 최대. "설비+전력 텍스트 1단계"가 상품으로 성립하는지 = **진산 결재 Q3**.

## §4 Ground Truth 2계층 + provenance 설계 (CBT 절벽 대응)

현 `exam_questions`에 출처 신뢰등급 컬럼 부재(실측) → 2호 스키마 신설:

```
answer_provenance: 'official'      -- 지필 확정답안(~2022-2회). Tier-1 GT
                 | 'reconstructed' -- CBT 복원분. Tier-2
                 | 'generated'     -- 파이프라인 B 생성물
+ provenance_source (출처 식별 — 출처 추적성 원칙 정합)
```

**단일 정책 문장 (비평 C-3 해소)**: GT 자격(AutoVerify V1 기준선 + V3 회귀 검증셋 구성)은 **Tier-1 전속**. Tier-2는 결정론 재검증(계산형=formula-engine 재계산 / 규정형=KEC 원문 대조 — 1호에 없던 도메인 강점) 통과 + 인간 검수 후 **학습 콘텐츠 자격만** 부여하며 "기출" 라벨 금지·"복원" 라벨 의무. 학습자 노출 허용 여부 = **결재 Q4**.
★비평 ③ (원리적 한계 명문화): **복원분의 오답지(distractor) 충실도는 어떤 결정론으로도 검증 불가**(원본 비공개) — 정답은 재검증돼도 보기 구성은 미보증. provenance를 문항 단위가 아니라 **정답/보기 분리 단위**로 라벨.
V2와 결정론이 상충하면 결정론 승(LLM 계산 금지 헌법). KEC 2021 이전 기출은 정합 필터 필수.

**★패밀리 계층 (이 검토의 핵심 발견)**: 전기 패밀리는 과목 7개로 4종목 커버 — **한계비용 구조를 바꾸는 것은 템플릿이 아니라 패밀리 계층**이다(공유 과목 코퍼스 1벌 = 적재·검수·개정이 4종목에 1회 상각). 권고 = 비가역 부분만 선결: **ID 네임스페이스를 과목-스코프로 확정**(`ELEC-KEC-###`·`ELEC-CIRC-###` — 종목-스코프 금지. 비평 C-1로 설계 간 충돌 해소: `EF-*` 안 폐기), 디렉토리 계층(`_family-electrical/`)은 패밀리 2종목째 확정 시 승격(가역). 깊이 차등은 노드에 소성하지 않고 **문항 계층이 자연 운반**(노드=과목 코퍼스 무태그, 종목=subjects.manifest 선언 — UPDATE 금지 Hard Limit 정합).

## §7 비평이 추가 발굴한 축 (계획·결재의 전제)

1. **vector baseline 도메인 이전 미측정 = 최대 공백**: 1호 83.3%는 한국어 산문 수치. 전기 문항은 수식·기호(√3, ω, μ₀, ∠, j) 밀도가 자릿수로 다른데 임베딩은 bge-m3 고정 — **spike S9 신설**(KEC 파일럿 노드+계산 문항 20~30개로 vector hit-rate 실측) 없이 GO 구조가 닫히면 서비스 바닥을 미측정한 채 착수하게 됨.
2. **수식 표기 canonical form 규약 = ID만큼 조기 소성**: D1 저장(유니코드? LaTeX?)·임베딩 입력·MC UI 렌더(KaTeX/MathJax 부재 실측) 3층 표기 규약을 첫 적재 전 확정 — 사후 변경 = 전량 SUPERSEDES 재적재.
