가축재해보험 총 지급보험금 계산 순서도

만든사람: 손평에듀 한종찬교수

가축재해보험의 총 지급보험금 계산 과정을 단계별로 시각화했습니다.

계산 시작

↓

1단계: 보험 종류 확인 (일부보험 여부)
보험가입금액 < 보험가액 인가요?

예 (일부보험)

↓

2단계: 목적물 손해 비례보상 금액 산정
Min( 손해액 x (보험가입금액 / 보험가액), 보험가입금액 )

예시:

손해액 500만원, 보험가입금액 400만원, 보험가액 500만원

500만원 x (400만원 / 500만원) = 400만원

Min(400만원, 400만원) = 400만원

※ 보충설명: 비례 계산된 금액은 보험가입금액을 초과할 수 없기 때문에, 보험가입금액 한도체크는 하지 않아도 됩니다. 다만 돼지질병위험보장특약의 경우에는 손해액과 보험가액이 다르며 손해액이 보험가액을 초과할수 있어 한도체크가 필요합니다.

↓

3단계: 목적물 손해 자기부담금 적용
(2단계 금액) - (2단계 금액 x 자기부담금 비율)

예시:

보상할 손해액 400만원, 자기부담금 비율: 10% (※실제 비율은 보험증권에 기재됩니다.)

400만원 - (400만원 x 0.1) = 400만원 - 40만원 = 360만원

아니오 (전부보험 또는 초과보험)

↓

2a단계: 보상할 손해액 산정 (전부/초과보험)
Min(손해액, 보험가액)으로 보상할 손해액 결정 (이득금지원칙)

예시 1 (전부보험):

손해액 500만원, 보험가액 500만원, 보험가입금액 500만원

Min(500만원, 500만원) = 500만원

예시 2 (초과보험):

손해액 700만원, 보험가액 500만원, 보험가입금액 1000만원

Min(700만원, 500만원) = 500만원

※ 보충설명: 손해액이 보험가액(최대손해액)을 초과할 수 없어 초과보험은 성립될 수가 없으며, 전부보험의 경우 보험가입금액과 보험가액(최대손해액)이 같으므로 보험가입금액을 초과할 수 없습니다. 따라서 가축에서는 한도체크는 의미가 없습니다.

↓

3a단계: 목적물 손해 자기부담금 적용
(2a단계 금액) - (2a단계 금액 x 자기부담금 비율)

예시 (2a단계 금액 500만원, 자기부담금 비율: 10% (※실제 비율은 보험증권에 기재됩니다.)):

500만원 - (500만원 x 0.1) = 500만원 - 50만원 = 450만원

↓

4단계: 비용손해 유형별 계산 시작
어떤 비용손해인가요?

잔존물 처리비용

↓

1. 잔존물 처리비용

1a단계: 비례보상 금액 산정
실제 비용 x (보험가입금액 / 보험가액)

예시:

잔존물처리비용 100만원, 보험가입금액 400만원, 보험가액 500만원

100만원 x (400만원 / 500만원) = 80만원

1b단계: 손해액의 10% 한도 적용
Min(1a단계 금액, 손해액의 10%)

예시:

비례보상 금액 80만원, 손해액 500만원의 10% 한도 50만원

Min(80만원, 50만원) = 50만원

1c단계: 자기부담금 적용
(1b단계 금액) - (1b단계 금액 x 자기부담금 비율)

예시:

적용 금액 50만원, 자기부담금 비율: 10% (※실제 비율은 보험증권에 기재됩니다.)

50만원 - (50만원 x 0.1) = 50만원 - 5만원 = 45만원

손해방지비용, 대위권 보전비용, 잔존물 보전비용

↓

2. 손해방지비용 등

2a단계: 비례보상 금액 산정
실제 비용 x (보험가입금액 / 보험가액)

규칙:

이 비용들은 목적물과 동일하게 비례보상하여 산정합니다.

예시:

손해방지비용 50만원, 보험가입금액 400만원, 보험가액 500만원

50만원 x (400만원 / 500만원) = 40만원

2b단계: 자기부담금 적용 여부
자기부담금은 **적용하지 않습니다**.

규칙:

계산된 금액이 보험가입금액을 초과하더라도 지급될 수 있습니다.

기타 협력비용

↓

3. 기타 협력비용

3a단계: 지급 금액 산정
실제 발생한 비용 **전액 지급**

규칙:

비례보상 적용하지 않음.

3b단계: 자기부담금 적용 여부
자기부담금은 **적용하지 않습니다**.

규칙:

계산된 금액이 보험가입금액을 초과하더라도 전액 지급됩니다.

↓

7단계: 총 지급보험금 합산 (A + B + C)

A = Min(목적물 최종 지급보험금 + 잔존물처리비용 최종 지급보험금, 보험가입금액)

B = (손해방지비용 보험금) + (대위권보전비용 보험금) + (잔존물보전비용 보험금) (보험가입금액을 초과해도 지급)

C = 기타 협력비용 (보험가입금액을 초과해도 지급)

총 지급보험금 예시:

A = Min(360만원 + 45만원, 400만원) = Min(405만원, 400만원) = 400만원

B (손해방지비용 등) = 40만원 (예시)

C (기타협력비용) = 0원 (예시)

총 지급보험금 = A (400만원) + B (40만원) + C (0원)

총 지급보험금 = 440만원

↓

계산 종료

⭐ 추가 중요 참고사항: 비용손해의 지급한도 요약 ⭐

  • 잔존물 처리비용: 목적물 보험금과 합계액이 보험가입금액을 한도로 지급. 단, 잔존물 처리비용 자체는 **손해액의 10%를 초과할 수 없음**. 일부보험 시 비례적용, 자기부담금 적용.
  • 손해방지비용, 대위권 보전비용 및 잔존물 보전비용: 계산된 금액이 **보험가입금액을 초과해도 지급**될 수 있음. 일부보험 시 비례적용, 자기부담금 미적용.
  • 기타 협력비용: **보험가입금액을 초과해도 전액 지급**되며, 일부보험/중복보험 시에도 비례보상하지 않고 전액 지급. 자기부담금 미적용.

본 순서도는 이해를 돕기 위한 일반적인 계산 절차를 나타냅니다. 실제 보험 계약은 약관 및 개별 상황에 따라 달라질 수 있습니다.
