## 2. 문제 정의 (수험생 Pain Point)

> 주의: 아래는 기능 설계 근거에서 역추출한 것으로, 실사용자 리서치로 검증된 바 없다(현 유저 기반 초기).
> 시장 관점 비판은 `docs/쪽집게(ThePick) — Opus 4.7 근본 재검토 보고서.md` §1 참조.

1. **암기가 특정 지점에서 반복적으로 무너진다** — 숫자/소수 계수/날짜·기간/긍부정/예외/절차 순서/
   작물 교차/나열 누락의 8종 혼동 유형. 기존 교재·인강은 이 지점을 개인별로 타격하지 못한다.
   (사용자UIUX/암기대상 인터랙션 방법론 §1-C)
2. **숲을 못 본다** — 목차는 평면 카탈로그라 어디가 하중벽(출제 빈발)이고 어디가 함정인지 안 보인다.
   지형도(가중치·긴장 반영)로 선행 조직자를 제공해야 한다. (사용자UIUX/지형도 방법론 §0·§1-4)
3. **과락 구조의 압박** — 1차는 매 과목 40점+ 그리고 평균 60점+. "과목별 최소 사수 세트"가 필요하다.
4. **AI 해설의 환각·오답은 곧 서비스 사망** — 65%를 60%로 잘못 말하면 끝. 정확성이 곧 제품이다.
   (재정립서 v2.0 §8)

## 10. 미해결 결정 사항 (진산 결재 필요 — RULE #5)

본 PRD가 스스로 결론짓지 않는 5건. 결재 채널 = `docs/plans/APPROVAL_DASHBOARD.md`.
★등재 상태 구분: **①~③은 어느 결재 원장에도 없는 신규 식별 항목**(본 PRD가 최초 상신 — 대시보드
등재 필요), ④는 로드맵 v2 §2C에 "조건부·후행"으로 이연 등재, ⑤만 대시보드 §A #5 실등재.

1. **[신규 상신] 타겟 페르소나 충돌** — 주 합격층 50대(55.8%) vs 모바일 80% 전제(v2.0). 실사용자 검증 0.
   → 베타 100명 단계에서 기기·연령 실측 후 UIUX 재결재 권고.
2. **[신규 상신] 2호 종목 문서 불일치** — v3.0 §15.2 "공인중개사 1순위" vs 실행은 전기기사 R5 결재(2026-07-04).
   → v3.0 원문에 개정 주석(amendment) 반영 필요. 실행 정본은 전기기사.
3. **[신규 상신] 1차 vs 2차 전략 균형** — 수험생 지출은 2차(합격률 5.9%)에 집중되나 현행은 1차 우선
   (promo-1st. 단 "2차 BATCH 후순위"는 구현 설계서 §10-1의 의도적 기결). → 1차 무료(획득) →
   2차 유료(수익화) 깔때기가 현행 암묵 전략인지 명시 결정 필요.
4. **[이연 등재] 북극성 대리 지표 확정** — 합격률 60%는 런칭 후에만 실측. E1 게이트(§4.3)의
   "근거보기 비공백 ≥?%" 결재값 미정 (로드맵 v2 §2C — "지금 액션 불요").
5. **[대시보드 §A #5] 유료 오픈 시점** — legal bundle 스프린트 발동 시점과 결합. 현행 기본값 = 무료 유지.

**비고**: 위 5건 외에 대시보드 §A에는 별도 미결 항목들이 실재한다(표본 감사 8행 / 계정 1스텝 3건 /
0039·0040 SQL 착수 / 잔여 고아 2 / autoverify 캘리브레이션 세트 재지정 / **L3 마이그 4장 production
적용**(#10, 불가역 — 가장 무거움) 등). PRD의 5건이 이를 대체하지 않는다 — 전체는 대시보드가 정본.
또한 스트릭 위젯 라이브는 원문 "게이미피케이션 Post-MVP" 결정과 긴장 관계(§7) — 사후 추인 대상.
