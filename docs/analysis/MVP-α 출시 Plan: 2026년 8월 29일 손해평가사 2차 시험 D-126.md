## 1️⃣ 타겟 재정의 (Claude Code 평가 갭 방지)

### 진산님 답 [A] YES의 정확한 의미

```
✅ 2차 시험 (8월 29일) 응시자가 진짜 타겟
❌ 1차 시험 (5월 9일) — D-14로 사실상 불가, 2027년 1차로 보류
```

### 2차 시험 응시자의 두 세그먼트

| 세그먼트                                                    | 규모 추정                           | 학습 시작 시점                  | 본 서비스 사용 시점        |
| :---------------------------------------------------------- | :---------------------------------- | :------------------------------ | :------------------------- |
| **A. 1차 면제자** (전회 1차 합격자, 2차 미응시 또는 불합격) | 약 1,000~2,000명                    | **이미 4월부터** 2차 준비 중    | **5월 말부터** 즉시 (알파) |
| **B. 2026년 1차 합격자**                                    | 약 5,000~7,000명 (1차 합격률 70%대) | **6/10 합격 발표 후** 본격 시작 | **6월 중순~** (베타 v1)    |

### 2차 시험의 특수성 — 서술형 실무 평가

```
1차: 객관식 (상법/농어업재해보험법령/농학개론) → 단순 암기
2차: 서술형 (농작물재해보험 + 손해평가 이론과 실무)
     → 산식 계산 + 사례 풀이 + 서술 답안 작성

핵심 학습 도구:
  ✅ 산식 계산기 (BATCH-1의 13 산식 = 적과전 종합위험 핵심)
  ✅ 산식 적용 사례 풀이 (Graph RAG 검색 + 단계별 풀이 가이드)
  ✅ 플래시카드 (개념/용어 빠른 복습)
  ⚠️ OX/빈칸 문제 (보조, 1차에 더 적합)
  ❌ 모의시험 자동 채점 (서술형 자동 채점 불가, Phase 후순위)

→ MVP-α는 "산식 계산기 + 사례 풀이 + 플래시카드" 3종 집중
```

**합격률 4.9% 시장에서 합격률 60% 도구의 가치**:
2차 합격률 4.9% (검색 결과)는 1,000명 응시 → 49명 합격. 본 서비스가 60%를 달성하면 동일 1,000명이 600명 합격 가능 — **시장 기회 명확**.

### 데이터 적재 (가-N) vs 학습자 UX (Epic α-N) 병렬 dependency

```
가-1 (BATCH-1)  ──┬──► Epic α-1 (W3-W5: PWA + 산식 5개 + 플카 30장)
                  │
가-2 (BATCH-2)  ──┼──► Epic α-2 (W6-W7: 산식 추가 + 알파 피드백)
                  │
가-3 (BATCH-3)  ──┼──► Epic α-3 (W8: 베타 v1 50명 인프라)
                  │
가-4 (BATCH-4)  ──┼──► Epic α-4 (W10: 베타 v2 100명 인프라)
                  │
가-5 (BATCH-5)  ──┼──► Epic α-5 (W12: 모의시험 모드)
                  │
가-6/7 (보조)    ─┴──► Epic α-6/7 (W13-W14: 약점 공략 + 안정화)

원칙:
  - 가-N 완료 = Epic α-N 진입 가능 (데이터 의존)
  - Epic α-N 진입 = 사용자 피드백 → 가-N+1에 반영 (피드백 루프)
  - 7월 말까지 BATCH 1~5 적재 완료 = 시험 범위 약 70~80% 커버
  - BATCH 6/7은 시험 후 점진 적재 (장기 유지보수)
```

## 3️⃣ MVP-α 정의

### 무엇인가 (포함)

```
✅ PWA 학습자 앱 (apps/web)
   - Astro + React Islands (기존 설계)
   - 모바일 한 손 조작 최적화

   - math.js AST 엔진 (formula-engine 기존 자산)
   - 입력 슬라이더 + 단계별 풀이 표시
   - 교재 페이지 참조 + 산출 근거 표시

✅ 플래시카드 학습 (BATCH 노드 → 카드 자동 생성)
   - SwipeCard UI (모바일 친화)
   - 단순 SM-2 알고리즘 (FSRS-5는 Phase 2 본격, MVP-α는 단순 버전)
   - 진도 저장 + 동기화

✅ 사례 풀이 가이드 (Graph RAG 활용)
   - 질문 입력 → 관련 노드 + 산식 자동 추천
   - 단계별 풀이 시연

✅ 진도 대시보드 (간단 버전)
   - 학습한 노드 수 / 마스터한 산식 수
   - 약점 영역 표시 (오답 산식 우선 노출)

✅ 학습자 인증 (Step 1-1 PBKDF2 + Step 1-4 JWT 활용)
   - 이메일 회원가입 + 로그인
   - 알파/베타는 무료 (결제 미적용)
```

### 무엇이 아닌가 (제외)

```
❌ 모의시험 자동 채점 (서술형 채점 = 사람 검수 필요, MVP-α는 셀프 채점)
❌ AI 암기법 자동 생성 (Phase 2 또는 베타 v2)
❌ 실 결제 (Year 1 무료 베타, Year 2 유료화)
❌ 1차 시험 대비 콘텐츠 (객관식 OX/빈칸은 Year 2 1차 사이클)
❌ 모바일 앱 (네이티브 X, PWA로 충분 — ADR-F01)
❌ 다크모드/접근성 고도화 (Phase 4 후순위)
❌ 푸시 알림 (Phase 4 후순위)
❌ 관리자 CMS 고도화 (검수는 진산님 직접 D1 쿼리로 충분)
```
