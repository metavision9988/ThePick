# 이음길에서 뭘 가져오면 쪽집게가 어떻게 좋아지나 — 쉬운 말 판

> 2026-08-06 · 기술 정본 = `catchall-역이식-분석-20260806.md` (이 문서는 그 번역본)
> 읽는 목적 = 진산이 "할지 말지, 뭐부터 할지"를 정하기 위한 판단 자료. 용어 없이 씀.

---

## 1. 지금 상태를 한 문장으로

> **쪽집게는 "이 내용이 교재와 맞다"는 걸 사람이 교재를 펴서 확인하는 방법 말고는 증명할 길이 없다.**

이게 모든 이야기의 출발점이다.

### 비유로

AI가 교재를 읽고 지식 카드를 만든다. 그 카드에는 이렇게 적혀 있다.

```
[카드] 적과전 감수과실수 산정 시 최대인정피해율은 65%를 적용한다
       출처: 교재 415쪽
```

여기서 문제는 **"교재 415쪽"이라고만 적혀 있다는 것**이다. 415쪽에 실제로 뭐라고 쓰여 있었는지는
카드 어디에도 없다. 그래서 이 카드가 맞는지 보려면 **사람이 415쪽을 펴야 한다.**

카드가 857장이면 857번 펴야 한다. 이게 지금 검수가 진산님한테 몰리는 이유의 전부다.
7월에 63장을 승격시킬 때 AI 9대를 붙여 원본 PDF를 다시 읽게 한 것도 같은 이유였다.

### 이음길은 어떻게 했나

카드에 **원문 문장을 같이 적어 둔다.**

```
[카드] ... 최대인정피해율은 65%를 적용한다
       출처: 교재 415쪽
       원문: "적과전 사고의 경우 최대인정피해율은 100분의 65를 초과할 수 없다"   ← 이 줄이 추가됨
```

이 한 줄이 있으면 컴퓨터가 물어볼 수 있는 질문이 생긴다.

- 이 원문 문장이 교재에 **진짜 있나?** (지어낸 문장 아닌가)
- 카드에 적힌 **65라는 숫자가 저 원문 안에 진짜 있나?** (60을 65로 잘못 옮기지 않았나)
- 원문 단어들을 **짜깁기해서 없는 말을 만들지 않았나?**

컴퓨터는 이걸 1초에 수천 장 검사한다. 사람은 안 봐도 된다.
사람은 그다음 단계 — **"이 원문을 이렇게 해석한 게 맞나"** — 라는 진짜 판단만 보면 된다.

**이게 핵심이다. 사람을 검사원에서 감사원으로 옮기는 것.**

## 2. 그래서 뭐가 좋아지나 — 물으신 세 가지 축 그대로

### ① 신뢰성 — 틀린 내용이 학습자에게 갈 확률이 내려간다

**지금**: AI가 만든 걸 사람 눈이 유일한 필터다. 사람은 지치고, 많이 볼수록 무비판이 된다.

**바뀌면**: 사람 앞에 자동 검사 네 겹이 먼저 선다.

| 검사               | 무엇을 잡나                             | 쪽집게에서 실제로 겪은 일                                                                                                            |
| ------------------ | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 인용이 진짜인가    | AI가 없는 문장을 지어냈나               | —                                                                                                                                    |
| 숫자가 원문에 있나 | 65%를 60%로 옮겨 적었나                 | **산식 55건이 코드와 DB가 다르게 등록돼 있음**(그중 24건은 계수·조건이 실제로 다름). 지금은 교재를 다시 펴서 대조하는 게 유일한 방법 |
| 짜깁기 아닌가      | 원문 단어를 재배열해 없는 말을 만들었나 | —                                                                                                                                    |
| **빠뜨린 게 있나** | AI가 안 읽고 지나간 교재 구간이 있나    | **7월에 AI 23대를 붙여 감사해서 146건 미적재를 발견**했다. 교재 1권 전체가 통째로 빠져 있었다                                        |

마지막 줄이 특히 크다. 지금은 **"빠뜨린 것"을 찾으려면 사람이 대규모 감사를 벌여야** 알 수 있다.
이음길은 이걸 자동으로 띄운다 — "이 조항은 아무도 안 읽고 지나갔음"이 매번 목록으로 나온다.

**덤으로 하나**: 지금 승격 근거는 "AI 9대가 63개 다 통과시켰다"인데,
통계로 따지면 **63개 전부 맞아도 "안심해도 된다"고 말하기엔 표본이 모자란다.**
(같은 방식으로 100개면 안심 범위에 들어온다.) 이걸 사람 감이 아니라 기계가 계산해서 찍어 준다.
이음길은 실제로 "8개 전부 맞았지만 표본이 적어 자동 승인 근거로는 부족함"을 보고서가 스스로 인쇄하게 만들어 놨다.

### ② 안정성 — 데이터가 조용히 망가질 구멍이 막힌다

지금 **열려 있는 구멍이 세 개** 확인됐다. 사고가 났다는 뜻이 아니라, **사고가 나면 못 막는다**는 뜻이다.

1. **안전장치가 꺼져 있다.**
   계산식·상수처럼 건드리면 위험한 파일을 고칠 때 자동으로 막아 주는 장치가 있다.
   그런데 **배선이 빠져서 아무것도 안 막고 있다.** 오늘 실제로 시험해 봤더니 그냥 통과했다.
   ★ 이건 이음길이 이 장치를 복사해 가자마자 발견해서 고쳤는데, **원본인 쪽집게는 그 수리를 못 받았다.**
   고치는 데 몇 줄이면 된다.

2. **폐기한 옛날 내용이 되살아날 수 있다.**
   개정으로 은퇴시킨 구버전 카드를 다시 살리는 걸 막는 장치가 없다.
   실수로 한 번 되살리면 학습자가 옛날 기준으로 공부한다.

3. **카드끼리 연결한 선(1,347개)은 지워도 아무도 안 막는다.**
   카드 본체는 삭제 금지가 걸려 있는데 연결선만 빠져 있다.

세 번째와 두 번째는 마침 이미 예약해 둔 작업 자리가 있어서 같이 처리하면 된다.

### ③ 최신성 — "언제부터 유효한지"를 아무도 안 본다

"언제부터 유효한지" 적는 칸은 만들어져 있는데, **학습자에게 보여줄 때 그 칸을 안 읽는다.**

> ## ⚠️ 정정 (2026-08-06, 실제 데이터를 열어 본 뒤)
>
> 이 자리에 처음 **"오늘이 8월 6일인데 학습자가 9일 뒤 시행될 내용을 현행 규정으로 배우고 있다"**고
> 썼다. **그건 과장이었고 사실이 아니다.** production 데이터 실측 결과:
>
> - 유효기간 칸이 채워진 카드 = **857장 중 0장**. 칸만 있고 값이 없었다.
> - 8월 15일 개정 카드 4장은 **전부 미승인 상태**라 애초에 학습자에게 안 나간다.
> - 승인된 카드 중 개정을 언급한 건 딱 1장인데, 그것도 _"(시행 2026.8.15 개정: …)"_ 이라고
>   **괄호로 따로 표시**해 두었다 — 현행인 척하지 않는다.
>
> **즉 지금 학습자가 잘못 배우고 있는 것은 없다.** 데이터를 확인하기 전에 단정한 것이 잘못이다.
> (공교롭게도 이건 이음길이 실수 로그에 적어 둔 _"부분만 보고 단정하지 마라"_ 와 같은 클래스다.)
>
> 남는 것은 **"장치가 없다"는 구조적 공백**이고 그건 실재하므로 이번에 고쳤다.
> 다만 급한 일이 아니므로 **실제 데이터를 건드리는 작업(값 채우기)은 하지 않았다.**

고치는 작업 자체는 아주 작다(두 줄). 그리고 고치다가 **더 넓은 구멍**을 하나 찾았다 —
학습자에게 "이 문제의 근거는 이 조항입니다"라고 출처를 보여주는 화면이,
**그 카드가 승인된 것인지조차 확인하지 않고 있었다.** 지금 데이터가 우연히 전부 승인분이라
사고가 안 났을 뿐, 미승인 카드를 참조하는 문제가 하나만 생기면 바로 새어 나간다. 이것도 같이 막았다.

그리고 이 축은 앞으로 계속 온다 — 법령·요령은 매년 바뀐다.
이음길은 여기에 한 겹 더 있다: **"유효기간이 끝난 조항을 현행처럼 뽑아내는 것"을 자동으로 잡아낸다.**
쪽집게도 같은 일이 벌어질 표면이 열려 있다.

## 3. 왜 이게 새로 만드는 것보다 싼가

- 이음길은 **원래 쪽집게 엔진을 복사해서 시작한 프로젝트**다(7월 14일).
- 두 서비스가 푸는 문제가 사실상 같다 —
  **원문(교재/조례)을 AI가 읽고 정리한 다음, 그게 맞다는 걸 증명해야 한다.**
  틀렸을 때 대가만 다르다(수험생이 틀린 답을 외운다 / 시민이 받을 돈을 못 받는다).
- 이음길은 지난 3주를 **거의 이 검증 장치에만** 썼다. 솔로 운영이라 사람 검수가 물리적으로 안 돌아갔기 때문이다.
- 그래서 지금 이음길에 있는 장치들은 **복지 도메인이 아니라 "AI 정리물을 믿을 수 있게 만드는 일" 자체에 붙어 있다.**
  그대로 맞는다.

**그리고 이미 결재가 끝나 있다.** 쪽집게에는 "이 검증 엔진을 만들자"는 계획서가 있고
7월 14일에 결재까지 났는데 3주째 코드가 0줄이다. 그 계획서 본문이 이미
**"이음길 것을 가져온다"**고 쓰여 있다. 즉 방향은 이미 정해져 있었고, 만들 물건이 그사이 저쪽에서 완성된 것이다.

## 4. 사업으로 보면 — 아마 이게 제일 중요하다

```
지금:   콘텐츠를 늘리려면 → 진산이 검수해야 함 → 진산이 병목 → 콘텐츠가 안 늘어남
바뀌면: 콘텐츠를 늘리면   → 기계가 먼저 거름  → 진산은 표본만 감사 → 사람 시간에 안 묶임
```

이건 2호(전기기사), 3호로 넓힐 때 결정적이다.
**종목이 늘면 검수할 양은 곱으로 늘어나는데 사람은 계속 한 명이다.**
검수를 사람 손에 묶어 둔 채로는 종목 확장이 성립하기 어렵다.

## 5. 정직하게 — 공짜는 아니다

좋은 얘기만 하면 판단이 안 되니 비용도 같이 적는다.

| 항목                            | 실제 비용                                                                                                                                                                   |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **기존 857장에 원문 채워 넣기** | 공짜 아님. 신규 카드부터만 적용하면 싸지만, 그러면 **"검사 통과 = 전부 검증됨"이라는 착각**이 생긴다. 기존 것도 채우는 쪽을 권한다                                          |
| **자동 승인을 켜는 것**         | 켜려면 **정답지(사람이 손으로 만든 기준 답안)**가 먼저 있어야 한다. 이게 진짜 비용이다. 정답지 없이 장치만 가져오면 전부 "사람 큐"로 보내진다 — 그게 올바른 기본값이긴 하다 |
| **여전히 사람이 해야 하는 것**  | "이 원문을 이렇게 해석한 게 맞나"는 기계가 못 한다. 다만 **양이 확 줄고, 질문 형태로 바뀐다**(원문 통독 → "제5조 원문의 이 금액이 이 값 맞습니까" 예/아니오)                |
| **안전장치를 켜는 순간**        | 지금까지 조용히 통과하던 작업이 갑자기 막힌다. 그래서 짝이 되는 장치와 **반드시 같이** 켜야 세션이 멈추지 않는다                                                            |

**그리고 이건 "잘못 만들었다"는 얘기가 아니다.**
지난 3주 쪽집게는 1차 서비스를 실제로 라이브에 올렸다. 그게 먼저인 게 맞았다.
그사이 이음길이 검증층을 팠을 뿐이고, 지금이 두 갈래를 합칠 시점이다.

## 6. 그래서 지금 정할 것 — 3개

| 순서  | 무엇                                   | 왜 지금                                                 | 크기                                |
| ----- | -------------------------------------- | ------------------------------------------------------- | ----------------------------------- |
| **1** | **안전장치 배선 고치기 + 시행일 반영** | 8월 15일 시행일이 9일 뒤. 안전장치는 지금 꺼져 있음     | 아주 작음 (오늘이라도)              |
| **2** | **카드에 원문 문장 같이 저장하기**     | **이게 관문이다.** 이거 없이는 3번이 작동할 대상이 없다 | 중간 (데이터 구조 변경 = 결재 필요) |
| **3** | **이음길 검증 엔진 가져오기**          | 이미 결재된 계획의 실행. 새로 짜지 않음                 | 중간                                |

1번은 결재 없이 바로 할 수 있다(위험 구역 아님).
2번은 데이터 구조를 건드려서 결재가 필요하다.
3번은 2번이 끝나야 의미가 생긴다.

**한 줄로 답을 주신다면**: "1번 바로 하고, 2번 승인" 이면 나머지는 순서대로 진행된다.

## 7. 한번에 할까, 나눠서 할까

**나눠서 한다. 5단계로.** 이유는 취향이 아니라 물리적 제약이다 —
**2번(원문 저장)이 끝나기 전에는 3번(검사기)이 검사할 대상이 없다.** 순서를 바꿀 수가 없다.

거기에 더해 ① 안전장치를 켜면 작업이 막히므로 짝과 같이 켜야 하고 ② 다섯 개를 한꺼번에 넣으면
좋아진 게 뭐 때문인지 몰라서 다음 판단 근거가 사라지고 ③ 라이브 서비스가 돌고 있어 검색 경로
변경은 따로 가야 한다.

```
0단계  지금 새는 것 막기            1~2일    ← 오늘 시작 가능, 결재 불요
1단계  안전장치 마저 채우기          2~3일    ← 진산 1줄
2단계  ★관문 — 카드에 원문 저장     1~2주    ← 진산 1줄
3단계  검사기 가져오기               2~3주    ← 자율
4단계  빠뜨린 것 찾기 + 자동화 준비  3~4주    ← 진산 1줄 (정답지)
5단계  나머지                       상시     ← 자율
```

**전 구간에서 진산이 하실 일은 「1줄 답변 3번」이다.**
