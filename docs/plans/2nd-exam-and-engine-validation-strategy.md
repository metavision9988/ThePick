## §3. Q3 — Self-Test 시뮬레이션 (Reality Anchor 적용 후 재정의)

### "Claude가 풀이 + 정답 체크" — **불가능 이유 3가지**

1. **Hard Rule 위반 — LLM에게 수식 계산 절대 금지**
   - 2차 핵심은 보험금/피해율 계산 (예: "수확감소보험금 산출하시오. 보험가입금액 X, 피해율 Y...")
   - Claude가 직접 계산 → Formula Engine 우회. 환각 발생 시 발견 불가.
   - 1차에도 계산 문항 다수 (재무관리/통계).

2. **자기 채점 편향 (CRITICAL RULE #4 — AI 자기 채점 금지)**
   - Claude 풀이 → Claude 비교 = 같은 hallucination이 양쪽에 반영됨
   - 인간 ground truth (큐넷 공식 정답)와 비교만 의미 있음
   - "Claude가 푼다" = 검증 자격 없음

3. **데이터 누설 — Blind 평가 불가**
   - 525문항 + 20문항 정답이 컨텍스트에 누적된 상태에서 풀이 = "정답 본 후 풀이"
   - 분리 컨텍스트 + 정답 마스킹 자동화 없이 시뮬레이션 무효

### 재정의 — **"Engine RAG 신뢰성 검증"** (성격이 다른 작업)

목적이 같다면 (= "엔진이 정답을 도출할 수 있는가") **Claude 직접 풀이는 잘못된 방법**.
올바른 방법:

```
[Question Text] → [Graph RAG retrieve] → [Constants DB resolve]
              → [Formula Engine compute] → [Answer derive]
              ↕ (자동 비교)
       [Ground Truth (큐넷 공식 정답)]
```

| 평가 차원       | 측정 방법                             | 합격 기준 (memory: 합격률 60% 목표) |
| --------------- | ------------------------------------- | ----------------------------------- |
| Retrieve 정확도 | 1차 525 객관식 정답 일치율            | 60%+                                |
| Formula 정확도  | 2차 20 계산형 100% 일치 (소수점 포함) | 100% (Hard Rule)                    |
| 출처 인용       | answer마다 LAW/FORMULA/CONCEPT FK     | 100%                                |
| Hallucination   | "근거 없는 답" 비율                   | 0% (refuse 의무)                    |

### 통합 위치

- 기존 `scripts/verify-engine-contracts.ts` 확장 (Cat 5A P0 시나리오 매트릭스에 통합 가능)
- 또는 `tests/engine-quality/exam-rag-eval.spec.ts` 신규 (vitest)
- ★ 권장: vitest spec + verify 스크립트 보고

### 결정 필요사항

- **D-Q3-1**: 평가 자동화 = vitest spec vs CLI 스크립트 → ★ 권장 vitest (CI 통합)
- **D-Q3-2**: 합격 기준 60% vs 80% → ★ 권장 단계적 (M1=60%, M2=80%, M3=95%)
- **D-Q3-3**: Engine RAG 미구현 부분 (Vectorize 등) 처리 → SKIP vs MOCK → ★ 권장 SKIP + 대시보드에 미커버 영역 표기

## §4. Q4 — 2차 모의고사 자동 출제 (Reality Anchor + 가능 조건)

진산: **"이것이 이 프로젝트의 핵심"** → memory "쪽집게 = 자격증 자동 훈련 엔진 MVP" 정합 ✅

### **불가능 이유 3가지** (신중한 가능 조건 도출)

1. **2차 채점 모호성 (서술형 부분점수)**
   - 큐넷 정답지는 단답형만 명확. 서술형 부분점수 기준은 학원별 다름 → 채점 ground truth 부재.
   - "이론 정답"이 여러 개일 수 있는 문항 (예: "보험 위험관리 정책수단 3가지를 쓰시오") → AI 채점 시 hallucination.

2. **계산 문항 안전성 (Formula Engine 의존)**
   - 2차 = 보험금 산출 핵심. Formula Engine + Constants DB + revisions 완비 필수.
   - 현재 Layer 1+2+3+4 완비 (193 constants / 157 formulas) 하지만 **정확도 100% 검증 미실시** → Q3 선행 의무.

3. **출처 추적성 미충족 시 approved 불가**
   - 생성 모의문제는 어떤 교재 페이지/법조문/기출 기반인가? (memory "출처 추적성 필수")
   - 모든 생성물에 `source_node_ids[]` 의무. LAW/FORMULA/CONCEPT FK 미충족 = `draft` 영구 격리.

### **가능 조건** (6개 모두 충족 시 가능)

| 조건                                       | 충족 상태                                                                                                  | 의무               |

| ② Formula Engine 100% 정답                 | ❌ Q3 선행 의무                                                                                            | 2차 20 계산형 검증 |
