## §0 TL;DR (3줄)

1. **서비스는 이미 라이브**(무료 1차 연습 + 인증 학습 기술적 개통)이고 테스트 전부 green.
   지금 진도를 막는 건 코드가 아니라 **"진산이 행 단위로 봐야 하는 검수·결재 큐"**다.
2. 그 큐를 전수 분류하면 **약 90%는 기계·AI 가 대신할 수 있는 유형**이다 — 그리고 그렇게
   해도 된다는 정책(AutoVerify 조건부 자동 승격)은 **2026-07-14 에 이미 결재됐다.** 실물만 없다.
3. 권고 = ①(즉시) 대기 중인 검수 87행을 "AI 재검증 + 표본 감사" 방식으로 일괄 처분
   ②(단기) `packages/autoverify` 실물 구현 ③(상시) 결재는 "예/아니오 1줄 + 권고 기본값"
   단일 대시보드로만. → 진산의 상시 부담 = **월 수 분 수준**으로 압축.

## §3 왜 쌓였나 (원인 3줄)

1. **헌법이 보수적**: Hard Limit "AI 생성 데이터 = draft, 인간 검수 후 approved" — 1차 정답 오류
   36 인시던트 이전 시대의 안전장치로 정당했음.
2. **검수 UX 부재**: 진산에게 오는 것이 "검수표 297줄 마크다운" — 전문가가 아니면 행당 수초가
   아니라 행당 수분이 됨. 질답형(AI 가 원문 하이라이트 + 초점 질문) 모듈이 없음.
3. **결재 단위가 카드**: 카드 1장 = 읽기 10분. 큐가 카드 더미로 오면 심리적 착수 비용이 큼.

## §4 권고 — 3단 해소안

### 권고 1 (즉시, 이번 세션 집행 가능): 대기 87행 소급 일괄 처분

- 방식: 각 draft 노드에 대해 **독립 검증 에이전트 재라운드**(PDF 원문 재추출 대조 — P1~P3 는
  이미 1회 통과) + 결정론 게이트(인용 실재성·무결성) 재실행 → 전건 PASS 분 = **"위임 승격"
  라벨로 approved 전이** + 진산 표본 감사분 **8행만** 선별 제시(무작위 + 경계사례).
- 근거: AutoVerify 개정 §1 5조건 중 캘리브레이션(조건 1)을 "기존 2중 독립 검증 통과 이력"으로
  갈음하는 **소급 1회 한정 예외** — 이 예외 자체가 본 카드의 결재 대상.
- 효과: 진산 부담 87행 → 8행(≈5분). E0-8 M1 출구 개방 → P4~P6 진행 가능.

### 권고 2 (단기 1~2주): `packages/autoverify` 실물 구현 (L3)

- 이미 기결된 설계(Class A/B/C + 5조건 + 기출 held-out 캘리브레이션)를 코드로: 결정론 게이트
  묶음 + Class 라우터 + 사람 큐 + 표본 감사 cron + 질답형 검수 콘솔(admin-web).
- 이후 신규 적재(2호 전기기사·E0-8 P4~P6·이음길)는 **처음부터 자동 승격 경로** — 진산은
  "원자료 전달 + 표본 감사"만.
- 착수 = L3 plan 작성부터 (자율 가능, 코드는 plan 결재 후 — 단 07-08 "결재 큐 금지" 지침을
  적용하면 plan 결재도 위임 처리 가능. §6 에서 택일).

### 권고 3 (상시): 결재 채널 단일화 — "1페이지 예/아니오 대시보드"

- 앞으로 모든 결재는 **카드를 읽게 하지 않는다.** 단일 문서(또는 아티팩트 웹페이지)에
  `[항목 1줄 요약 | 권고 기본값 | 안 하면 생기는 일 1줄]` 표로만 유지. 진산 응답 형식은
  "전부 권고대로" / "N번만 보류" 두 가지.
- 사실상 07-07 위임 체제 + 07-08 "구현→결과 보고" 지침의 명문화. 신규 프로세스 아님.
