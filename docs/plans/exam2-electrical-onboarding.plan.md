### 2.3 패밀리 계층 (전기 4종목 = 과목 7개)

- **지금 확정(비가역)**: ID 네임스페이스 = **과목-스코프** `ELEC-{SUBJ}-###`(예: ELEC-KEC-211-2, ELEC-CIRC-001) — 종목-스코프 금지. CHECK·ID 패턴은 첫 적재 시 DDL 소성 → 이것만 맞추면 F-A→F-B 승격이 파일 이동 수준 가역.
- **이연(가역)**: `_family-electrical/` 디렉토리 승격은 패밀리 2종목째(산업기사 등) 확정 시 — 레포 내 rule-of-three.
- **깊이 차등**: 노드 = 과목 코퍼스(종목 무태그, UPDATE 금지 정합) / 종목 차등은 **문항 계층 + subjects.manifest**가 자연 운반 / 노드 단위 미세 차등 실수요 발생 시 `node_exam_applicability` 매핑 테이블(노드 불변).
- **Hard Limit 확장(D-5)**: "패밀리 공유 과목 노드 수정 시 참조 전 종목 검토" 명문화.
