## §0 G-1 약식 (Reality Anchor)

- **천장 정합 (R1, 기 조사)**: 무인 자동 구축의 업계 천장 = "초안 품질"(Stanford RegLab — Lexis+ AI
  환각 17%, `saas-platform.ceiling.md` §R1-6). 본 설계는 무인 신뢰 보증을 주장하지 않는다 —
  **결정론 게이트 + held-out 캘리브레이션 + 인간 표본 감사**의 3중 구조가 천장과 정합.
- **불가능 이유 3 (선서)**: ① LLM 자기평가는 승격 근거가 될 수 없다(기결 — confidence 단독 불인정)
  ② GT 없는 Class C(생성물)는 기계 검증 불가 — 자동 승격 영구 제외 ③ 캘리브레이션 없는 임계값은
  허구 — held-out 실측 전 자동 승격 활성화 금지(§1 조건 1).
- **스키마 존재 ≠ 데이터 populate**: 캘리브레이션은 반드시 production 실데이터/실 GT 로 — 픽스처 금지.

## §1 기능 계약 (기결 5조건의 코드 번역)

입력 = 적재 후보 배치(노드/산식/상수/문항 draft rows + 출처 앵커). 출력 = 행별 3진 판정
**{PROMOTE | QUEUE | REJECT}** + 기계 판독 게이트 리포트. **무음 폐기 금지** — REJECT 도 사유·행 보존.

| 기결 조건                | 코드 번역                                                                                                                                                  |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. held-out 캘리브레이션 | `calibrate()` — GT 세트(기출 held-out 회차/골든) 처리 → 오류율 실측 → 클래스별 임계 파일 영속. 임계 파일 없으면 `promote()` 는 **전건 QUEUE**(fail-closed) |
| 2. 결정론 게이트 전 PASS | 게이트 레지스트리(§3). LLM 신호는 게이트가 될 수 없다(타입 수준에서 배제)                                                                                  |
| 3. FAIL/경계 = 사람 큐   | QUEUE 판정 행은 검수 큐 테이블(또는 리뷰 시트 생성)로 — 출구는 승격 아니면 큐, 둘뿐                                                                        |
| 4. 적재 후 상시 감사     | 자동 승격분 무작위 표본 재검증 cron(ops.yml) + 표본 감사 시트 자동 생성                                                                                    |
| 5. 오류 → 배치 재검증    | 표본 감사 FAIL 1건 = 동일 source 배치 전체 QUEUE 강등 + 임계 재캘리브레이션 트리거                                                                         |

## §2 Class 라우터 (기결 §2 그대로)

| Class | 대상                                   | 판정 경로                                                                          |
| ----- | -------------------------------------- | ---------------------------------------------------------------------------------- |
| A     | 기출 문항·공식 정답·골든 검증식        | official GT 100% 일치 + 게이트 PASS → PROMOTE 자격                                 |
| B     | 지식 노드·법령 조문·상수(원문 대조형)  | 인용 실재성(G3 바이그램) + 값 정합 + 무결성 + 캘리브레이션 임계 → 조건부 PROMOTE   |
| C     | 암기법·변형문제·distractor·해설(GT 無) | **자동 승격 불가 영구** — QUEUE 고정(역방향 검증·이중 합의는 큐 우선순위에만 반영) |

라우팅 키 = 콘텐츠 타입 + GT 가용성 선언(종목 팩이 주입 — FRAMEWORK T3). 미선언 타입 = C 취급(fail-closed).

## §3 게이트 레지스트리 (전부 결정론 — 초기 6종)

1. **G-AV-CITE** 인용 실재성: description 의 원문 발췌가 출처 문서에 실재 (catchall G3 바이그램 역이식
   - LCS 보조지표 — 속성-스왑 공격 클래스 방어, 기결 §1-2)
2. **G-AV-NUM** 값 정합: 행 내 모든 수치 토큰(기간·금액·비율·~~조문번호~~)이 원문 추출본에 존재 - ⛔ **문면 충돌 상신 (2026-08-10, 독립 리뷰 M-8 — Silent Pivot 정정)**: 구현(STAGE 3
   `packages/autoverify/src/numeric.ts`)은 **조문번호를 값에서 제외**한다. 이 게이트 문면과 정반대이며,
   구현 시점에 상신 없이 갈라진 것을 리뷰가 적발했다. **실측 근거**: 조문번호를 값으로 세면
   `제8조`·`제1호`·노드 ID 의 숫자가 "주장 수치"로 잡혀 **파일럿 58장 중 30장이 reject** 로 튀었고
   전부 과탐이었다. 조문번호는 **도메인 값이 아니라 주소**이므로 `65%`·`30일`과 같은 잣대로 볼 수 없다. - ⇒ **권고: 문면을 구현에 맞춘다**(조문번호를 G-AV-NUM 대상에서 제외). 단 조문번호 **위조**
   (`제3자→제4자`·`제1호→제7호`)는 값 검사가 아니라 **3-1/3-3 축자 대조**가 잡는다 —
   실제로 그 회귀 테스트가 존재한다(`verify-card.test.ts` "조문·호 번호 위조는 검출한다").
   즉 커버리지 손실 없이 축만 옮기는 정정이다. **진산 사후 거부권 대상**(대시보드 이력 등재).
3. **G-AV-ONTO** Ontology Lock: ID 패턴·edge_type 어휘·타깃 실재성 (기존 gate_check 계열 재사용)
4. **G-AV-GRAPH** 무결성: 신규 고아 0·끊긴 엣지 0·SUPERSEDES 순환 0 (packages/quality graph-integrity 재사용)
5. **G-AV-ANSWER** 정답 대조(Class A): 공식 정답지와 100% 일치 (RC-2 위치라벨-answer 게이트 통합)
6. **G-AV-DUP** 중복/충돌: 동명·동조문 기존 노드 탐지 → 자동 판정 아닌 QUEUE 사유로 표면화

## §5 단계

- **Phase 0 (코어)**: 게이트 6종 + Class 라우터 + 캘리브레이션 하네스 + 3진 판정. 부트스트랩 캘리브레이션
  = E0-8 P1~P3 63행(진산 위임 승격분 = 레이블 확보된 세트) + 기출 held-out 1회차.
- **Phase 1 (운영)**: 승격 SQL 이미터 + 표본 감사 cron(ops.yml 잡 — DO-1 패턴) + 감사 시트 생성기.
- **Phase 2 (콘솔)**: 질답형 검수 모듈(admin-web — 원문 하이라이트 + 초점 질문. catchall 공용 설계).
- 각 Phase 완료 = Binary Gate(§6) + 4-Pass 독립 리뷰. Phase 0 완료 전 production 자동 승격 실행 금지.

## §6 Binary Gates

- **G-AV-1**: 캘리브레이션 파일 부재 시 promote() 전건 QUEUE (fail-closed 테스트)
- **G-AV-2**: Class C 입력이 어떤 경로로도 PROMOTE 불가 (타입+런타임 이중 차단 테스트)
- **G-AV-3**: 속성-스왑 변조 픽스처(수치 교환·주체 교환) 주입 시 G-AV-CITE/NUM FAIL (적대 픽스처 ≥10)
- **G-AV-4**: held-out 캘리브레이션 실행 리포트 실재 + 오류율 수치 영속 (fabricate 불가 — GT 대조)
- **G-AV-5**: REJECT/QUEUE 행 전수 보존 (입력 N = PROMOTE+QUEUE+REJECT 합 검산)
- **G-AV-6**: 승격 이미터 출력이 status_transitions INSERT 만 (knowledge_nodes UPDATE 0 — Hard Limit)
- **G-AV-7**: 표본 감사 FAIL → 동일 배치 강등 트리거 테스트
