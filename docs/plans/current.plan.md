  지목한 burned 코퍼스. 파일럿 수치는 **"이 엔진이 이 표본에서 무엇을 잡았나"** 이고,
  **"엔진의 일반 성능"이 아니다.** held-out 확보는 STAGE 4 선결(§A #8).
- **description 은 요약본**이다. 인용과 축자 일치할 이유가 없으므로 3-1 을 description 에 걸면 안 된다 —
  3-1 의 대상은 **인용 ↔ 원본 PDF**, 3-2/3-4 의 대상은 **카드 주장 ↔ 인용**이다. 층을 섞으면 무의미해진다.
- **PDF 가구 혼입 8건**(`법제처 … 국가법령정보센터`·페이지 푸터) — STAGE 2 리뷰가 기록한 잔여물.
