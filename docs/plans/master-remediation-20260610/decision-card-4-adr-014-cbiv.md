## 권고: **(b) C 축소 개정** — §2.3 기존 이연 처분(MASTER_PLAN.md:91)과 정합. A안 러너가 실측으로 보호 능력을 입증(133건 검출→수리)했고, R-BATCH 직격 공백 2개(상수 대조·Golden 회귀)만 C 안 내부 게이트로 못박으면 풀스펙 없이 개정 위험의 핵심을 막는다. 단 Stage 2/6 공백은 명시 잔존 — R-BATCH 규모 확정 시 재평가 조건 부기.
