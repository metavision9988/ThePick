## 종합 판정 (G-1 형식)

방향 전환은 **조건부 지지** — 기존 원칙(Hardest-First 3원칙·rule-of-three)의 *정밀화*다. 단:

| 가설                       | 판정            | 핵심                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| H1 달력→게이트 전환 건전성 | **조건부 지지** | ADR-007의 실체는 달력이 아닌 원칙("Extract After Two") — "Year 2"는 proxy였고 게이트는 proxy를 실변수로 교체. **단 달력의 숨은 기능(차단선) 승계 필수**: 게이트 = 기계 판정 조건 + "통과 전 차기 단계 코드 0 LOC" 명문 + ADR-007 supersede 결재. engine-export 6문서가 1개월 내 stale 된 것이 "게이트 전 미래 대비 산출물은 부패한다"의 자체 실증                                                                                                                                                            |
| H2 "1호 성공" 정의         | **지지**        | 합격률 60% 게이트 = 구조적 비현실(런칭 후 수개월~1년·자기선택 교란) → **후행 관측 지표로 격하**. 대안 = E0(엔진 정확성)+E1(제품). 교정: F1~F7은 "전부 구현"이 아니라 **"전부 판정 종결"**(각 F가 검증됨-PASS 또는 G-1 R5 결정 기록)로 — F6를 통째 게이트화하면 졸속 구현 역유인                                                                                                                                                                                                                              |
| H3 2호 선정                | **조건부 지지** | **전기기사 2호 = 정의상 모순 확정** — QG-M2("Adapter가 engine 무수정으로 동작") vs 복소수=타입 계약 재설계 사전 확정(FormulaScope=Record<string,number>) + Vision NotImplementedError. 전기기사의 올바른 역할 = **3호**("코어 계약을 의도적으로 깨는 시험" — 그 수정 목록이 범용 추상화의 입력). 2호 = 코어 무수정으로 어댑터 축을 최대로 흔드는 후보(공인중개사: CASE_LAW 노드타입·법령 조문군 300+·판례 스키마 / [추정] 소방·산업안전: 실수 스칼라 산식 — R3 spike 대상). 최종 선정 = 사업 변수 결합, 진산 |
| H4 closed-domain 확장      | **후단 지지**   | eval·생성 검증의 도메인별 재정의 = 필수(현 정확성 기계 전부가 시험 3요소 기출GT·기계채점·합격 위에 있음). 3층 모델은 유효하되 **GT 공급 계약이라는 신규 층** + 코어를 "지식 코어/학습 제품 코어"로 분할 필요 — 단 그 분할은 E3-2 원장(2·3호 실증 데이터) 기반으로만 (1사례 추상화 90% 오류 반복 금지)                                                                                                                                                                                                        |
| H5 "동시 다발" 논거        | **함정 지지**   | 현 병목 = 작업량이 아니라 **단일 인간(진산)의 결재·검수 큐**(미체크 결재 12건+) — 2호 착수는 큐를 곱절로. 모델 능력은 오류 생산 속도도 올림(자가리뷰 0건 vs 독립리뷰 C9 전력). **역설**: "AI 급변" 논거가 실제로 지지하는 것은 "지금 만든 범용 인프라가 가장 빨리 감가상각된다" = ③을 늦추라는 방향. **유일 안전 적용 = 2호 후보 R3 spike 병렬화**(타 자격증 PDF 1건 구조화 실측 — G-1이 오히려 요구, 전 게이트와 병렬 허용)                                                                                 |

### E2 — 2호 실증 게이트 (QG-M2 계승)

E2-0 선정 규칙: engine 코어 수정이 사전 식별되는 후보 배제(전기기사류 → 3호) / E2-1 R3 spike 산출물 / E2-2 **Adapter 코어 수정 0 LOC**(git diff 증명, 수정 발생 시 전건 목록화=E3 입력) / E2-3 2호 기출 정답 100% 대조 / E2-4 2호 golden N≥30 + E0-4 동일 하한 / E2-5 시험 간 격리 오염 0 (QG-M3).

### E3 — 범용 인프라 착수 게이트 (rule-of-three)

E3-1 2호+3호 E2 졸업(3호 = 코어 계약을 깨는 축 ≥1: 복소수 또는 Vision) / E3-2 **코어 수정 diff 누적 원장**(추상화 설계의 유일 입력) / E3-3 범용 가이드 문서 작성 = E3-1 후에만(이전 작성분 STALE 라벨) / E3-4 ADR-007 supersede Accepted.

### E4 — closed-domain 확장 게이트

E4-1 도메인 G-1 R1~R5 전수 / E4-2 **GT 공급 계약**(정답 검증 주체=외부 전문가·갱신 주기·골든 경로, 골든 검수 주체 ≠ 측정 주체 — 순환편향 차단) + N≥30 실측 1회 / E4-3 코어 모듈 적합성 판정표(FSRS·채점·셔플 등 시험-제품 가정 모듈 포함/제외 — E3-2 원장 기반으로만) / E4-4 closed-ness 실측(경계 밖 질의 비율 표본 + honest refusal 경계).

## 놓친 리스크 (검증자가 추가 식별)

1. **게이트 침식(goalpost drift)** — 게이트 문구 개정을 L3급 결재로 묶을 것 ("재사용 55~75%" 무실증 단언 전력).
2. **베타 측정 창 부재** — 연속 2개월 명시 없으면 스냅샷 게이트로 퇴화.
3. **2호 실증의 숨은 전제** — 자동 파이프라인이 1호 production 적재의 실경로조차 아니었음(수동 SQL) + tables[] 무음 폐기는 "자동 가동 순간 발화" → E1-4로 흡수.
4. **개정 주기 가정 파괴(E4)** — 사업 도메인은 주 단위 변경 가능, 인간 검수 처리량 병목 사전 산정 필요.
