## 이 디렉토리가 무엇인가

신규 종목(2호 전기기사, 3호+ …)을 온보딩할 때, 콘텐츠 적재는 매번 새로 설계하지 않는다.
검증된 절차·게이트·검수 프로토콜을 **템플릿에서 인스턴스화**한다. "정확도는 모델 신뢰가 아니라
게이트가 담보한다"는 원칙(원형 §0)이 종목이 바뀌어도 유지되도록 하는 것이 이 층의 목적이다.

## 파일

| 파일                                | 역할                                                                 |
| ----------------------------------- | -------------------------------------------------------------------- |
| `README.md` (본 파일)               | 인스턴스화 절차 + 버전 스탬프 규약 + 불변/파라미터 구분              |
| `content-load.playbook.template.md` | 콘텐츠 적재 플레이북의 종목-파라미터 원형 (`{{PLACEHOLDER}}` 치환식) |

> 향후 추가 예정(별도 신설 시 본 표 갱신): `review-sheet.template.md`(검수표 서식 단독 분리), 종목별 게이트 오버라이드 규약. 현재는 `content-load.playbook.template.md` §7·§4에 인라인.

## 인스턴스화 절차 (신규 종목 콘텐츠 적재 착수 시)

1. `content-load.playbook.template.md`를 `docs/plans/{exam_id}-content-load.playbook.md`로 **복사**(원본 템플릿은 수정 금지 — 원형 보존).
2. 아래 §"종목별 파라미터"의 `{{...}}` 토큰을 해당 종목 값으로 **전수 치환**(치환 누락 = 게이트 대상. 인스턴스에 `{{` 잔존 0건 확인).
3. 인스턴스 헤더에 **버전 스탬프**(아래 규약) 기입 — 어느 템플릿 버전에서 파생됐는지 추적.
4. 종목 registry(`exams/{exam_id}/registry`) + 원문 저장소(`docs/manual-{exam}/` 등) + 대상 인벤토리(`docs/audit/{exam}-content-coverage-inventory-*.md`)를 §9 참조에 고정.
5. §8 결재란은 **비운 채** 상신 — 패키지별 진산 결재(RULE #5) 전 착수 금지.

## 버전 스탬프 규약 (산출물 추적성 — D-7 필수)

템플릿에서 파생된 **모든 산출물**(인스턴스 플레이북, `*-insert.sql`, `*-knowledge-graph.json`, 검수표, 리뷰 보고서)은 상단에 스탬프를 단다. 목적: 어느 템플릿 버전·어느 종목·어느 패키지에서 나왔는지 = stale 추적(가드레일 #14 — stale = 사고 진앙) + 재현성.

- Markdown 산출물: 문서 상단 blockquote 또는 HTML 주석
- SQL/JSON 산출물: 파일 선두 주석(`-- STAMP …` / `// STAMP …` 또는 JSON `_meta` 필드)

```
PLAYBOOK-STAMP
  template:         docs/playbooks/_template/content-load.playbook.template.md
  template_version: v1.0 (2026-07-04)
  exam:             {{exam_id}}          # 예: jeon-gi-gi-sa
  package:          {{PKG_ID}}           # 예: P1
  instance:         docs/plans/{{exam_id}}-content-load.playbook.md
  produced:         {{YYYY-MM-DD}} · {{model}}
```

> 템플릿을 개정하면 `template_version`을 올리고(본 파일 §변경 이력) 기존 인스턴스에 STALE 판단 대상임을 표기. 게이트 문구·불변 규칙 변경은 **L3급 결재**(원형 §8 + EXPANSION_GATE "게이트 문구 개정 = L3급 결재" 규칙 승계).
