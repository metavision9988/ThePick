## 도메인 의미 정리

### 그림 #6 (book_p416) — 낙엽률 조사 시각 가이드

좌: 가지별 낙엽수/착엽수 산출 방법

- 가지에 1~12 번호로 잎 위치 표시
- 낙엽률 50% 예시: 착엽수 6일, 낙엽수 6일
- → F-02 (낙엽률 = defoliated / (defoliated + attached)) 의 시각적 정의

우: 태풍피해 착엽 판단 4 케이스

- "잎의 일부가 찢겨진 경우" → 착엽
- "잎의 50% 미만에서 찢긴 경우" → 착엽 2건 (동일 패턴)
- "여러 곳이 찢어지고, 찢기고, 찢겼으나 전체 대비 50% 미만인 경우" → 착엽
- → 태풍피해를 입었어도 50% 이상 손상이 아니면 착엽으로 분류 (CONCEPT 노드 의미)

### 그림 #8 #9 (book_p426) — 적과전 종합위험 II 보험금 산정 패턴

#8 (착과감소 있음): 평년착과수 > 적과후착과수

- 차이 = 착과감소량
- 적과후착과수에서 다시 과실손해 발생 가능
- F-08 착과감소보험금 = max(착과감소 - 미보상감수량 - 자기부담감수량, 0) × 가입가격 × 보장수준

#9 (착과감소 없음): 평년착과수 ≈ 적과후착과수

- 적과후착과수가 그대로 보장 기준
- F-09 과실손해보험금 = max(적과후누적감수량 - 자기부담감수량, 0) × 가입가격

→ 두 케이스 모두 "기준착과수" 가 보장 단위. 그림이 이를 시각적으로 명료화.
