## 자료 영역

| 섹션                                   | 영역                      | 작물                                                                      |

| §1 품목별 표본구간 면적                | 표본구간 규격 (㎡, m × m) | 메밀 / 맥류(밀·보리·귀리) / 차 / 콩·팥 / 단호박 / 시금치                  |

| §3 생산비보장(노지) 표본구간 이랑 길이 | 이랑 길이 × 구·구간       | 당근 / 무 / 브로콜리 / 파(대파·쪽파·실파) / 고추 / 배추 / 양상추 / 시금치 |
