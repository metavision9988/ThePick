## 1. SPOF (Single Point of Failure) — 진산님 1인 검수자

### 1.1 본질

본 시스템 (Year 1 손해평가사 단계) 의 검수자 = **진산님 1인**.

- BATCH 1~14 적재의 모든 검수
- 큐 1/2/3 의 모든 결정
- AI 추천 1-click 채택 (Rule 29)
- Rollback 결정 (Rule 31)

### 1.2 SPOF 위험

| 시나리오                | 영향                                                  |
| :---------------------- | :---------------------------------------------------- |
| 진산님 부재 (병가/휴가) | BATCH 적재 중단, 큐 1/2 적체                          |
| 큐 1 30+ 건 적체        | BATCH-N+1 진입 차단 (CBIV 통과 후에도 인간 결정 대기) |
| 진산님 burnout          | 시스템 사망 (북극성 위반)                             |
| 잘못된 결정 누적        | Rollback 안전망에도 불구하고 audit 부담               |

### 1.3 ADVOCATE 강조사항

> _"진산님은 본 프로젝트의 단일 SPOF. SPOF 의 burnout = 시스템 사망."_

## 2. Year 1 정책 — 단일 검수자 수용 (명시)

### 2.1 수용 근거

- Year 1 은 "엔진 검증" 단계 — 진산님 직접 검수가 도메인 학습 + 시스템 정밀화 동시 달성
- 외부 검수자 위임 시 도메인 학습 비용 발생
- 1인 검수자 + 자동화 (CBIV 99%) = 균형

### 2.2 안전 장치 (Year 1)

1. **Rule 30** (비교 통계 미표시) — 자기 압박 회피
2. **Rule 29** (AI 자동 채택 금지) — 결정 책임 명확
3. **Rule 31** (Rollback 안전망) — 잘못된 결정 회복 가능
4. **휴가 정책**: 진산님 부재 시 **BATCH 적재 중단** (안전 우선, 강제 휴식 보장)
5. **큐 적체 알림**: 큐 1 누적 30건 도달 시 진산님 알림 (속도 강요 X, 인지만)

### 2.3 진산님 부재 시 처리

- **사전 공지**: 진산님이 admin-web 에서 "검수 일시 중단" 토글
- **자동 차단**: 신규 BATCH 적재 PR 생성 차단 (CI 가 진산님 active 상태 확인)
- **큐 보존**: 기존 큐 1/2/3 항목은 유지, 복귀 시 처리
- **Rule 31 연장**: 부재 기간 동안 Rollback 기한 자동 연장 (다음 BATCH 진입 전까지)

## 3. Year 2 정책 — 백업 검수자 1명 추가 (예정)

### 3.1 진입 조건

- Year 1 BATCH 14 적재 완료
- 멀티시험 plugin 추가 (예: 공인중개사) → 검수 부담 증가
- 진산님 단독 부담 한계

### 3.2 백업 검수자 후보

- 신뢰 인력 (예: 손해평가사 자격증 보유자)
- 권한: 큐 1/2 결정 (큐 3 차단 정정은 진산님 전용 유지)
- audit log 에 reviewer_id 명시

### 3.3 권한 분리

| 액션                                        | Year 1 | Year 2                                    |
| :------------------------------------------ | :----- | :---------------------------------------- |
| 큐 1 (의미 중복) Merge / Reject / Keep Both | 진산님 | 진산님 + 백업                             |
| 큐 2 (출제영역) Approve / Reassign          | 진산님 | 진산님 + 백업                             |
| 큐 3 (CBIV 차단) Auto-Fix / Manual Fix      | 진산님 | 진산님 전용                               |
| `/cbiv override` (CBIV 강제 우회)           | 진산님 | 진산님 전용                               |
| Rollback                                    | 진산님 | 자기 결정만 (백업은 자기 결정만 Rollback) |
| Hard Rule 변경                              | 진산님 | 진산님 전용                               |

## 4. 정량 지표 (Year 1 monitoring)

진산님 부담 측정 (UI 미표시, audit log 만):

| 지표                    | 임계값     | 알림                          |
| :---------------------- | :--------- | :---------------------------- |
| 큐 1 누적               | 30건       | 진산님 알림 (속도 강요 X)     |
| 일일 검수 시간          | 4시간 초과 | 휴식 권고 (UI 알림)           |
| Rollback 비율           | 5% 초과    | AI 추천 정확도 분석 (Rule 29) |
| 보류 (Investigate) 누적 | 10건       | 패턴 분석 + 시스템 보강       |

## 5. 본 문서의 무결성

- ❌ 진산님 부재 중 자동 BATCH 적재 (Rule 29 위반)
- ❌ 진산님 burnout 알림 무시
- ❌ Year 2 백업 검수자 권한이 진산님 권한 초과
- ❌ Rollback 권한 본인 결정 외 적용 (백업 검수자가 진산님 결정 Rollback X)

본 무결성이 깨지면 시스템 SPOF 사망.
