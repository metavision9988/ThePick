## R1 — 업계 천장 (외부 실측 요약, 상세·URL = 리서치 원문)

1. **인용 "표시"는 커머디티, 인용 "검증"은 소수** — RAG SaaS(Glean·Onyx·Writer)는 인용 링크 표시
   수준. 검증을 제품화한 곳은 Vectara(HHEM 사실성 점수 — 확률 모델, 한국어 미지원) 정도.
   **결정론 게이트(인용 실재성·값 정합·무결성) + draft/승격 거버넌스 + temporal graph 를 하나의
   신뢰 계층으로 묶어 파는 제품 = 조사 범위에서 미확인 (빈자리 ①).**
2. **문서→지식그래프 자동 구축**은 도구 단계(Neo4j Builder 무료 도구·Lettria·MS GraphRAG 라이브러리) —
   전부 "구축해주되 검증은 고객 몫" 모델. 구축물 정확도를 게이트로 보증하는 제품 없음.
3. **개정 감지→영향 분석(Revision Watch 동일 문제)은 영어권 금융 RegTech 에서 성숙 상용**
   (Ascent·4CRisk — ING 1,800시간→2.5분 사례). 단 전부 대기업 컴플라이언스 엔터프라이즈 계약.
   **한국어 법령·조례·교재 축은 공백 (빈자리 ②).**
4. **검증 계층은 독립 제품 카테고리로 성립** (Patronus·Galileo·Ragas) — 단 전부 확률적 judge 모델.
   결정론 게이트 + 도메인 적재 파이프라인 결합형은 미확인.
5. **한국 시장** = RAG 챗봇 구축 SI 단계 (업스테이지=모델·추출층, 올거나이즈·스켈터랩스=엔터프라이즈
   RAG 구축) — 신뢰 계층(출처 검증·개정 추적·승격 거버넌스)을 제품 전면에 세운 곳 검색상 부재.
6. **★무인 자동 구축의 천장 실증**: 수십억 달러 법률 DB + RAG 로도 Lexis+ AI 환각 17%·Westlaw 33%
   (Stanford RegLab, 사전등록 연구). LLM 추출 F1 은 좋은 조건 ~0.95, 도메인 특화·비정형에서 급락.
   ⇒ **업계 천장 = "무인 구축은 초안 품질까지"** — 인간 개입 없는 신뢰 보증 공개 사례 없음.
   우리의 게이트+캘리브레이션+감사 설계가 천장과 정합 (과잉 설계 아님)이며, 동시에
   **self-serve 무인 SaaS 로는 누구도 신뢰를 보증 못 한다는 한계선이기도 함.**
7. **시장 천장 경고**: 수직 신뢰 SaaS 단독 성장의 반례 실재 — Compliance.ai 는 고객 65개사
   규모에서 피인수. 기술 빈자리 ≠ 큰 시장 [추정 축 분리 필요].
8. **사업 모델 천장**: vertical AI 의 지배적 진입 = **구축 동행(FDE)형 → 반복 패턴 제품화 → 셀프서브**
   (Palantir 원형, Harvey $1,200/석/월·20석 최소 — 신뢰+도메인 특화가 범용 KB 대비 10~50배 프리미엄).
   처음부터 self-serve 로 성공한 수직 지식구축 사례는 조사상 드묾.
