### 1.6 2차 템플릿(대역통과) — 아키텍처 일반화 실증 (2026-07-06)

1차 리뷰가 남긴 한계("템플릿 1종만 관통")를 해소하고, MAJOR-2 수정(포트=템플릿 정본)이 실제 일반화되는지 검증하기 위해 **2번째 템플릿 = 직렬 RLC 대역통과(출력=R)** 추가:

- **registry 구동 전환**: `src/references.py` 신설 = `reference_id → {derive(lcapy 계수), reference(원값 폐형식), steps}`. `generate.py`는 오케스트레이션만(solve=순수 lcapy 추출). **동적 코드 실행 0**(Hard Limit 준수 — 템플릿 `reference_formula`는 검수/문서용, 계산은 승인된 파이썬 함수만).
- **신규 물리**: 대역통과 = 극점은 저역통과와 공유(토폴로지 불변)하되 **대역폭 BW=R/(2πL)·하단/상단 차단주파수** 신규 산출. 교차검증은 공유 키 전수(극점+BW+차단주파수), lcapy 계수 유래 vs 원값 유래 = 독립 경로.
- **H(∞) 게이트 추가**: 출력탭을 `(H(0),H(∞))` 쌍으로 유일 식별 — **저역통과(1,0)·대역통과(0,0)·고역통과(0,1)**. DC 이득만으론 대역통과와 고역통과(둘 다 H(0)=0)를 구별 못 하나, H(∞)가 잡는다(테스트 실증: 고역통과 오배선이 대역통과 기준 H(∞) 단독으로 거부).

**실측**: 저역 2 + **대역 33 seed 전부 PASS**(극점=저역 동일 확인, V1 rel_err ≤ 4.4e-16 — 수치·건수 3차 검토 정정 §1.8. 기하평균·BW 항등은 `_cutoffs` 구성상 대수 항등 = 회귀 가드이며, 물리 독립 검증은 −3dB backstop이 담당. H(0)/H(∞) 기대 일치). 게이트 실검증 **12/12**(다중 템플릿 관통 + 상이 물리 직접검증 + 차단주파수 −3dB 독립확인 + G1 뮤테이션 가드 + 출력탭 이중(H0·H∞) + G2). ⇒ **단일 파이프라인이 서로 다른 시험 개념(저역통과 필터 vs 대역통과 필터+대역폭)을 템플릿 교체만으로 생성 = 킬러 서비스 스케일 경로 실증**. 독립 2렌즈 리뷰 = §1.7.

## 4. 발견·한계·에스컬레이션

1. **결정론 정답의 원천 = lcapy AST 유도**(LLM 계산 0 — Hard Limit 준수). 폐형식은 교차검증용일 뿐, 정답은 solver 유도값.
2. **스코프 = 클래스 A(1차 회로이론)만**. 수변전 단선도(커스텀 심볼+규칙엔진)·시퀀스(부울 시뮬레이터)=클래스 B·C=백로그 BL-3 별도 엔진.
3. **템플릿 2종(저역통과·대역통과) 관통** — registry 일반화 실증(§1.6). 실서비스 = 인간승인 토폴로지 템플릿 라이브러리 확대 필요(각 템플릿 = 진산/과목전문가 승인 + `references.py` 승인 물리함수 = 결정론 변형 검수단위, playbook W4 "템플릿 승인제" 결재 사안). 신규 토폴로지(병렬 RLC 등 극점식이 다른 계열)는 `reference()` 폐형식을 독립 검증 후 등록.
4. **렌더 시각 품질 = 진산 확인 필수**(게이트 미충족분). SVG 레이아웃 청결도(G3)는 자동판정 미구현 — 현 PoC는 well-formed·라벨 위치까지만.
5. **web 렌더 통합 미실증**: playbook은 "기존 web 렌더 확인"까지 요구 — 본 PoC는 정적 JSON+SVG 산출까지. apps/web 통합은 2호 배선 단계(별건).
6. **게이트 끝점 한계(2차 리뷰 MINOR-3)**: 출력탭 검증은 `(H(0),H(∞))` 끝점 이득만 제약 — 중대역 피크이득 `H(jω0)`·분자 스케일은 미검증. 현 단일-명명소자 탭에선 오배선이 항상 끝점을 바꿔 잡히나(실취약 아님), 답에 **대역내 크기를 포함하는 미래 템플릿·다탭 토폴로지** 도입 시 피크이득 게이트 추가 필수 = **신규 템플릿 리뷰 체크리스트 항목**("출력탭별 (H0,H∞) 유일성 + 필요 시 피크이득 검증").
7. **신규 템플릿 체크리스트 (3차 검토 §1.8 확정판)**: ①element↔포트 정합·직렬 단일루프·접두 유일 = **V1-T 기계 게이트가 자동 차단**(수동 검수 불요) ②비직렬 토폴로지(병렬 RLC 등) = **렌더러 확장 선행**(V1-T 완화는 렌더러가 해당 토폴로지를 정확히 그린 후) ③`reference()` 폐형식 독립 검증 후 registry 등록 ④(H0,H∞) 탭 유일성 + 필요 시 피크이득 ⑤`expected_dc_gain`+`expected_hf_gain` 둘 다 필수(미선언 = 게이트 LOUD) ⑥**기대이득·폐형식 동시 오저작은 게이트가 못 잡는다** — 인간 승인이 최종 방어선 ⑦모순전원류 전원 구성 오류는 transfer() 미검출 — 템플릿은 단일 소스 유지.
