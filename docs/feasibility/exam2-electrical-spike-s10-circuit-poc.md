### 1.5 독립 검증 반영 (review `wf_a1fd2c69`, 2렌즈 적대·실행검증)

물리 에이전트: **392 R/L/C 조합 전수 정확**(4유효숫자 diff 0, V1 최악 2.7e-16), 교차검증 비순환 확인. 게이트 에이전트가 **실질 결함 2 MAJOR 발굴 → 전건 수정**:

- **MAJOR-1(테스트 무효)**: 종전 `test_gate`가 V1 단락으로 **G1을 실검증 못함**(G1 블록 삭제해도 PASS = 뮤테이션 증명). → 게이트 id 실발화 assert + **포지티브 컨트롤**(V1·G4 통과·G1만 위반) 추가로 G1 회귀 검출.
- **MAJOR-2(분자 맹점)**: 극점(ω0,ζ)은 출력탭 불변 → 코드가 템플릿 포트 무시(하드코딩)·게이트 분자 맹점 → L↔C 스왑이 f0/Q/ζ 정확한 채 통과(모순 JSON). → **포트=템플릿 정본 구동** + **DC 이득 게이트**(H(0)=기대값) 추가 = 출력탭 오배선 LOUD 거부.
- MINOR: R=0 principled 거부(계수 비유한·ζ=0)·G2 판별 단위검증·broad except 협소화(ImportError 재전파)·matplotlib figure 누수 close.

재검증: 게이트 실검증 **7/7 PASS**(사일런트 드롭 0) + 생성 무회귀 13/13. 인라인 4관점 + 독립 2렌즈 = CRITICAL 0.

### 1.6 2차 템플릿(대역통과) — 아키텍처 일반화 실증 (2026-07-06)

1차 리뷰가 남긴 한계("템플릿 1종만 관통")를 해소하고, MAJOR-2 수정(포트=템플릿 정본)이 실제 일반화되는지 검증하기 위해 **2번째 템플릿 = 직렬 RLC 대역통과(출력=R)** 추가:

- **registry 구동 전환**: `src/references.py` 신설 = `reference_id → {derive(lcapy 계수), reference(원값 폐형식), steps}`. `generate.py`는 오케스트레이션만(solve=순수 lcapy 추출). **동적 코드 실행 0**(Hard Limit 준수 — 템플릿 `reference_formula`는 검수/문서용, 계산은 승인된 파이썬 함수만).
- **신규 물리**: 대역통과 = 극점은 저역통과와 공유(토폴로지 불변)하되 **대역폭 BW=R/(2πL)·하단/상단 차단주파수** 신규 산출. 교차검증은 공유 키 전수(극점+BW+차단주파수), lcapy 계수 유래 vs 원값 유래 = 독립 경로.
- **H(∞) 게이트 추가**: 출력탭을 `(H(0),H(∞))` 쌍으로 유일 식별 — **저역통과(1,0)·대역통과(0,0)·고역통과(0,1)**. DC 이득만으론 대역통과와 고역통과(둘 다 H(0)=0)를 구별 못 하나, H(∞)가 잡는다(테스트 실증: 고역통과 오배선이 대역통과 기준 H(∞) 단독으로 거부).

**실측**: 저역 3 + **대역 33 seed 전부 PASS**(극점=저역 동일 확인, V1 rel_err ≤ 4e-16, BW/차단주파수 기하평균 항등 √(f_L·f_H)=f0 성립, H(0)/H(∞) 기대 일치). 게이트 실검증 **12/12**(다중 템플릿 관통 + 상이 물리 직접검증 + 차단주파수 −3dB 독립확인 + G1 뮤테이션 가드 + 출력탭 이중(H0·H∞) + G2). ⇒ **단일 파이프라인이 서로 다른 시험 개념(저역통과 필터 vs 대역통과 필터+대역폭)을 템플릿 교체만으로 생성 = 킬러 서비스 스케일 경로 실증**. 독립 2렌즈 리뷰 = §1.7.

### 1.7 2차 독립 리뷰 반영 (review `wf_8a7d60c6`, 2렌즈 뮤테이션 실행검증)

물리 렌즈: 대역통과 답 전 392그리드 정확(−3dB 독립 탐색 worst 1.6e-13). 게이트 렌즈: **무결 5건 명시**(get_reference 미등록 LOUD·H(∞) kill-test[체크 삭제 시 9/10 FAIL]·탭 (0,0) R에서만 유일·동적실행 0[eval/exec 부재]·게이트 재현). 결함 **2 MAJOR + 4 MINOR 전건 반영**:

- **MAJOR-1(사일런트 오답)**: asks 심볼이 derive 산출에 없으면 0.0 조용히 방출 → **인라인 리뷰서 이미 LOUD 가드**(심볼 부재 = `SolverGateError`, bogus 심볼 실증).
- **MAJOR-2(교차검증 키집합 공백)**: crosscheck가 reference 키만 순회 → derive-only/ref-only/rv=0 키 조용히 skip → **`set(derived)==set(reference)` 계약 강제**(불일치 LOUD) + rv=0 절대오차 폴백.
- **MINOR-1(차단주파수 독립성 과대진술)**: derive·reference가 공통 `_cutoffs` 호출 → 공식 자체 미검증 → 도크스트링 정직화 + **test_gate −3dB 독립 backstop**(`|H(j2πf_c)|=1/√2`, 실측 0.7071/0.7071).
- **MINOR-2(과감쇠 대역통과 25.8%)**: Q 무제한 → 선택도 밴드 **Q∈[0.7,500]** 추가(과감쇠 재난수화, 30-seed 무고갈 확인).
- **MINOR-3(끝점 이득만)**: §4-6 명문화(아래).
- **MINOR-4(관통 테스트 약함)**: G1==PASS만 확인 → **상이 물리 직접 assert**(극점 공유·f_low<f0<f_high·BW 항등).

재검증: 게이트 **12/12** + 생성 무회귀(저역 2 + 대역 33). 인라인 4관점 + 독립 2렌즈 = **CRITICAL 0**.

## 4. 발견·한계·에스컬레이션

1. **결정론 정답의 원천 = lcapy AST 유도**(LLM 계산 0 — Hard Limit 준수). 폐형식은 교차검증용일 뿐, 정답은 solver 유도값.
2. **스코프 = 클래스 A(1차 회로이론)만**. 수변전 단선도(커스텀 심볼+규칙엔진)·시퀀스(부울 시뮬레이터)=클래스 B·C=백로그 BL-3 별도 엔진.
3. **템플릿 2종(저역통과·대역통과) 관통** — registry 일반화 실증(§1.6). 실서비스 = 인간승인 토폴로지 템플릿 라이브러리 확대 필요(각 템플릿 = 진산/과목전문가 승인 + `references.py` 승인 물리함수 = 결정론 변형 검수단위, playbook W4 "템플릿 승인제" 결재 사안). 신규 토폴로지(병렬 RLC 등 극점식이 다른 계열)는 `reference()` 폐형식을 독립 검증 후 등록.
4. **렌더 시각 품질 = 진산 확인 필수**(게이트 미충족분). SVG 레이아웃 청결도(G3)는 자동판정 미구현 — 현 PoC는 well-formed·라벨 위치까지만.
5. **web 렌더 통합 미실증**: playbook은 "기존 web 렌더 확인"까지 요구 — 본 PoC는 정적 JSON+SVG 산출까지. apps/web 통합은 2호 배선 단계(별건).
6. **게이트 끝점 한계(2차 리뷰 MINOR-3)**: 출력탭 검증은 `(H(0),H(∞))` 끝점 이득만 제약 — 중대역 피크이득 `H(jω0)`·분자 스케일은 미검증. 현 단일-명명소자 탭에선 오배선이 항상 끝점을 바꿔 잡히나(실취약 아님), 답에 **대역내 크기를 포함하는 미래 템플릿·다탭 토폴로지** 도입 시 피크이득 게이트 추가 필수 = **신규 템플릿 리뷰 체크리스트 항목**("출력탭별 (H0,H∞) 유일성 + 필요 시 피크이득 검증").
