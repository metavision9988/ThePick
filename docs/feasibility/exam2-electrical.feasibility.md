## R3 — Feasibility Spike 설계 (전면 미측정 — 실행은 R5 후)

| #      | 측정 항목                                                                | 게이트 초안                                                   |
| ------ | ------------------------------------------------------------------------ | ------------------------------------------------------------- |
| S1     | 기출↔출제기준 세세항목 매핑률                                            | ≥90% → "출제기준=분모" 채택. 미달 시 무경계 재판정            |
| S2     | 문제은행 반복률 실측(통설 50~80% 검증)                                   | 게이트 아님 — 실측치가 산출물(과락 모델·ROI 전제)             |
| S3     | 지필 기출 파싱 수율 + 공식 정답 대조                                     | 정답 매칭 **100%**(불일치 1건 = 원인 규명, 1호 규칙 동일)     |
| S4     | 그림 의존도 재검증(3~5회분 전수, 도해/수식 렌더 분리)                    | 과목별 확정치 → 그림 정책·스코프 산정 근거                    |
| S5     | KEC 파일럿 20~30노드 적재→기출 근거 역검증                               | 회수율 ≥90% + 수치 불일치 0건(QG-3 동형)                      |
| S6     | 계산 문항 formula-engine 표현률(17함수 기준 표현/우회/불가 3분류)        | 표현+우회 ≥70% → 화이트리스트 확장 L3 plan 근거               |
| S7     | 복원분 결정론 재검증 가능률(N=30)                                        | 실측치 = Tier-2 정책(Q4) 채택 근거                            |
| S8     | KEC 전문 hwp(40.3MB) 파싱 수율(표 포함)                                  | S5의 선행 게이트                                              |
| **S9** | **전기 도메인 vector baseline**(파일럿 노드+문항 20~30, bge-m3 hit-rate) | **서비스 바닥 실측 — 비평 신설, 미실측 시 GO 구조 성립 불가** |
