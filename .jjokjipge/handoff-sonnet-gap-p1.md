## §8. 진산 운영 절차 (사람이 하는 일)

1. **세션 1 (실행)**: §1 프롬프트 복붙 → 산출물 4종 + ESCALATE 목록 확인. 막히면 세션이 알아서 멈춤.
2. **세션 2 (독립 리뷰)**: §7 프롬프트 복붙 → CRITICAL 0 확인 (있으면 세션 1 재개해 수정 지시).
3. **검수 (진산)**: `gap-P1-review-sheet.md` 행당 APPROVE/FIX/REJECT — 원문 발췌 vs 본인 지식 대조,
   행당 수초. **FIX+REJECT 비율을 기록**해 두세요 — 플레이북 §8 품질 게이트(P4·P5 진입 기준) 입력값.
4. **적재 (진산 게이트)**: 검수 통과 후 아무 세션에서 "P1 적재 진행" 지시 →
   `wrangler d1 execute thepick-db-production --file=docs/batch-load/gap-P1/gap-P1-insert.sql --remote`
   → 카운트 검산 → 무결성 러너 재실행 → batch-loadmap·inventory 기록 → 커밋. (Fable 세션 권장 —
   production 쓰기·검증 체인이라.)
5. **다음**: P1 FIX율 양호 시 P2(부록 요령·규정·고시)·P3(개정 4건) — 동일 구조, §1 프롬프트의 P1 만
   교체 + 플레이북 §8 해당 패키지 체크 먼저.
6. ESCALATE 목록이 나오면 그대로 두면 됩니다 — Fable 세션/결재 큐에서 처리 (Sonnet 산출물에 섞이지
   않는 것이 정상).
