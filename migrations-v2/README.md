# migrations-v2 — exam-generic 스키마 정본 (프레임워크 T5)

> **근거**: 2026-07-04 멀티트랙 R5 결재 "프레임워크 정본 = packages/(코드) + docs/playbooks/\_template/(프로세스) + **migrations-v2/(스키마)**" + Revision Watch plan §9 Q7 위임 결재(2026-07-07).
> **역할**: 종목(exam) 무관 **재사용 스키마 템플릿**의 단일 보관처. 신규 종목(2호 전기기사 등) D1 초기화 시 여기서 인스턴스화한다.
> **관계**: `migrations/`(루트) = **1호 손해평가사 인스턴스 적용 이력**(0001~00NN, production 순차 적용 — 불변 원장). migrations-v2 는 그 대체가 아니라 **exam-generic 추출본**이다. 1호에 적용할 SQL 은 여전히 `migrations/` 슬롯으로 작성(선례: 0041/0042).

## 규약

1. **디렉토리 = 모듈 단위** (`revision-watch/`, `core/`(예약), …). 모듈 내 파일은 `0001_*.sql` 순번.
2. **exam-generic 조건**: 종목 하드코딩 금지(Hard Rule 16/17 — exam_id 는 컬럼/파라미터로만). 테이블·트리거 구조는 전 종목 동일 스키마 전제(종목별 D1 분리 배포 모델).
3. **인스턴스화**: 신규 종목 D1 에는 모듈 순서대로 그대로 적용. 1호(기존 production)에는 루트 `migrations/` 슬롯으로 **동치 SQL** 작성 후 적용 — 양쪽 드리프트는 동치 주석(원본 참조)으로 추적.
4. 적용 = 인간 인증 게이트(wrangler --remote). 이 디렉토리는 **정본 텍스트**이지 적용 이력이 아니다.
